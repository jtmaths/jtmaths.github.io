1 The Big Idea

In Year 1, algebra was mostly about expressions: expanding, factorising, solving. In Year 2 the focus shifts to functions — rules that turn inputs into outputs — and to the tools that make later calculus possible.

Think of a function as a machine. Year 2 asks four questions about it: What can go in? (domain) What can come out? (range) What happens if I chain two machines? (composite) Can I run it backwards? (inverse).

Why it matters. Partial fractions are needed to integrate rational functions and to expand them as series. Inverse functions explain why $\ln x$ undoes $\mathrm{e}^x$ and why $\arcsin x$ needs a restricted domain.
2 The Language You Need
WordMeaningExample
FunctionA mapping where every input has exactly one output.$\mathrm{f}(x) = x^2$
DomainThe set of allowed inputs.$x \geqslant 0$
RangeThe set of outputs actually produced.$\mathrm{f}(x) \geqslant 0$
One-oneDifferent inputs always give different outputs.$\mathrm{f}(x) = 2x + 1$
Many-oneTwo or more inputs share an output.$\mathrm{f}(x) = x^2$, $x \in \mathbb{R}$
CompositeOne function applied to the output of another.$\mathrm{fg}(x) = \mathrm{f}(\mathrm{g}(x))$
InverseThe function that undoes $\mathrm{f}$.$\mathrm{f}^{-1}(x)$
ModulusThe size of a number, ignoring its sign.$|-3| = 3$
Rational expressionOne polynomial divided by another.$\dfrac{x+1}{x^2-4}$
ImproperNumerator degree $\geqslant$ denominator degree.$\dfrac{x^2}{x-1}$
Partial fractionsA sum of simpler fractions equal to one fraction.$\dfrac{2}{x-1} + \dfrac{3}{x+2}$
$\mathrm{f}^{-1}(x)$ is not $\dfrac{1}{\mathrm{f}(x)}$. The $-1$ means "inverse function", not "reciprocal". If $\mathrm{f}(x) = 2x$, then $\mathrm{f}^{-1}(x) = \tfrac{x}{2}$, not $\tfrac{1}{2x}$.
3 The Five Core Techniques
1 — Partial fractions
$\dfrac{px + q}{(x - a)(x - b)} \equiv \dfrac{A}{x - a} + \dfrac{B}{x - b}$  ·  repeated factor: $\dfrac{B}{x - b} + \dfrac{C}{(x - b)^2}$
2 — Modulus equations and inequalities
$|A| = |B| \iff A^2 = B^2$  ·  $|x - a| < b \iff a - b < x < a + b$
3 — Composite functions
$\mathrm{fg}(x) = \mathrm{f}\big(\mathrm{g}(x)\big)$: apply $\mathrm{g}$ first
4 — Inverse functions
$y = \mathrm{f}(x)$, make $x$ the subject, swap · domain of $\mathrm{f}^{-1}$ = range of $\mathrm{f}$
5 — Combined transformations
$(p, q)$ on $y = \mathrm{f}(x)$ $\longmapsto$ $\left(\dfrac{p - c}{b},\; aq + d\right)$ on $y = a\,\mathrm{f}(bx + c) + d$
Worked Example — Several techniques in one question

$\mathrm{f}(x) = |2x - 4|$, $x \in \mathbb{R}$, and $\mathrm{g}(x) = x + 1$, $x \in \mathbb{R}$. (a) State the range of $\mathrm{f}$. (b) Explain why $\mathrm{f}$ has no inverse. (c) Solve $\mathrm{fg}(x) = \mathrm{g}(x)$.

①(a) $y = |2x - 4|$ is a V with vertex $(2, 0)$, so the range is $\mathrm{f}(x) \geqslant 0$.
②(b) $\mathrm{f}$ is many-one: e.g. $\mathrm{f}(1) = \mathrm{f}(3) = 2$. Only one-one functions have inverses.
③(c) $\mathrm{fg}(x) = |2(x + 1) - 4| = |2x - 2|$, so solve $|2x - 2| = x + 1$.
④$2x - 2 = x + 1 \Rightarrow x = 3$ (check: $|4| = 4$ ✓).
⑤$-(2x - 2) = x + 1 \Rightarrow 3x = 1 \Rightarrow x = \tfrac13$ (check: $\left|-\tfrac43\right| = \tfrac43$ ✓).
⑥$x = \tfrac13$ or $x = 3$.
This one question uses domain and range, one-one functions, composites and modulus equations. Expect the topics in this section to be mixed together.

5 Common Mistakes to Avoid
Composite in the wrong order. $\mathrm{fg}(x)$ means $\mathrm{g}$ first. If $\mathrm{f}(x) = x^2$ and $\mathrm{g}(x) = x + 1$, then $\mathrm{fg}(x) = (x+1)^2$ but $\mathrm{gf}(x) = x^2 + 1$.
Range in terms of $x$. Write "$\mathrm{f}(x) \geqslant -3$", not "$x \geqslant -3$". The range is about outputs.
Not checking modulus solutions. In $|A| = B$ where $B$ contains $x$, a "solution" that makes $B$ negative must be rejected.
Missing a term for a repeated factor. $\dfrac{\ldots}{(x+1)(x-2)^2}$ needs three partial fractions, including $\dfrac{B}{x-2}$.
Splitting an improper fraction directly. If the numerator's degree is at least the denominator's, there is a polynomial part. Divide first.
Horizontal transformations the wrong way. $\mathrm{f}(x + 3)$ moves the graph left; $\mathrm{f}(2x)$ squashes it by a factor $\tfrac12$.

7 Practice Questions

Ten questions drawing on the whole of this section. Work each one through before opening the solution.

Question 1

Simplify $\dfrac{x^2 - x - 12}{x^2 - 16}$.

▶ Show solution

$\dfrac{(x - 4)(x + 3)}{(x - 4)(x + 4)} = \dfrac{x + 3}{x + 4}$

Question 2

Express $\dfrac{3x + 7}{(x + 1)(x + 3)}$ in partial fractions.

▶ Show solution

$3x + 7 \equiv A(x + 3) + B(x + 1)$.

$x = -1$: $4 = 2A$, $A = 2$.   $x = -3$: $-2 = -2B$, $B = 1$.

$\dfrac{2}{x + 1} + \dfrac{1}{x + 3}$

Question 3

Solve $|4x - 3| = 9$.

▶ Show solution

$4x - 3 = 9 \Rightarrow x = 3$;   $4x - 3 = -9 \Rightarrow x = -\tfrac32$.

Question 4

Solve $|x + 1| \leqslant 4$.

▶ Show solution

$-4 \leqslant x + 1 \leqslant 4 \Rightarrow -5 \leqslant x \leqslant 3$.

Question 5

$\mathrm{f}(x) = 3x + 2$ and $\mathrm{g}(x) = \dfrac{1}{x}$, $x \neq 0$. Find $\mathrm{fg}(x)$ and $\mathrm{gf}(x)$, stating any value that must be excluded from the domain of $\mathrm{gf}$.

▶ Show solution

$\mathrm{fg}(x) = 3 \times \dfrac{1}{x} + 2 = \dfrac{3}{x} + 2$, $x \neq 0$.

$\mathrm{gf}(x) = \dfrac{1}{3x + 2}$, which needs $3x + 2 \neq 0$, so $x \neq -\tfrac23$.

Question 6

$\mathrm{f}(x) = \dfrac{x + 4}{2}$, $x \in \mathbb{R}$. Find $\mathrm{f}^{-1}(x)$ and verify that $\mathrm{f}\mathrm{f}^{-1}(x) = x$.

▶ Show solution

$y = \dfrac{x + 4}{2} \Rightarrow x = 2y - 4$, so $\mathrm{f}^{-1}(x) = 2x - 4$.

$\mathrm{f}\mathrm{f}^{-1}(x) = \dfrac{(2x - 4) + 4}{2} = \dfrac{2x}{2} = x$ ✓

Question 7

The point $(2, 8)$ lies on $y = \mathrm{f}(x)$. Find its image on $y = \tfrac12\mathrm{f}(x + 3) - 1$.

▶ Show solution

$x + 3 = 2 \Rightarrow x = -1$;  $y = \tfrac12(8) - 1 = 3$.

Image $(-1, 3)$.

Question 8

Express $\dfrac{x^2 + 3x - 1}{x + 2}$ in the form $Ax + B + \dfrac{C}{x + 2}$.

▶ Show solution

$x^2 \div x = x$; subtract $x^2 + 2x$ to leave $x - 1$.

$x \div x = 1$; subtract $x + 2$ to leave $-3$.

$x + 1 - \dfrac{3}{x + 2}$, so $A = 1$, $B = 1$, $C = -3$. (Check: substituting $x = -2$ into the numerator gives $4 - 6 - 1 = -3$ ✓)

Question 9

$\mathrm{f}(x) = (x + 1)^2 + 2$, $x \geqslant -1$. Find $\mathrm{f}^{-1}(x)$, state its domain, and describe how the graphs of $y = \mathrm{f}(x)$ and $y = \mathrm{f}^{-1}(x)$ are related.

▶ Show solution

Range of $\mathrm{f}$: $\mathrm{f}(x) \geqslant 2$.

$y = (x + 1)^2 + 2 \Rightarrow x + 1 = \sqrt{y - 2}$ (positive root since $x \geqslant -1$).

$\mathrm{f}^{-1}(x) = \sqrt{x - 2} - 1$, domain $x \geqslant 2$.

Each graph is the reflection of the other in the line $y = x$.

Question 10

$\mathrm{f}(x) = \dfrac{5x - 1}{(x + 1)(2x - 1)}$, $x > \tfrac12$.

(a) Express $\mathrm{f}(x)$ in partial fractions.  (b) Show that $\mathrm{f}(1) = 2$.  (c) The function $\mathrm{g}$ is defined by $\mathrm{g}(x) = |x - 3|$, $x \in \mathbb{R}$. Find $\mathrm{gf}(1)$, and solve $\mathrm{g}(x) = 2x$.

▶ Show solution

(a) $5x - 1 \equiv A(2x - 1) + B(x + 1)$.

$x = -1$: $-6 = -3A$, $A = 2$.   $x = \tfrac12$: $\tfrac32 = \tfrac32 B$, $B = 1$.

$\mathrm{f}(x) = \dfrac{2}{x + 1} + \dfrac{1}{2x - 1}$

(b) $\mathrm{f}(1) = \dfrac{2}{2} + \dfrac{1}{1} = 2$ ✓ (or directly, $\dfrac{4}{2 \times 1} = 2$).

(c) $\mathrm{gf}(1) = \mathrm{g}(2) = |2 - 3| = 1$.

$|x - 3| = 2x$: case $x - 3 = 2x$ gives $x = -3$, but then $2x = -6 < 0$: reject.

Case $3 - x = 2x$ gives $x = 1$; check $|1 - 3| = 2 = 2(1)$ ✓. So $x = 1$.
