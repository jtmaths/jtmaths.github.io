1 Secant, Cosecant and Cotangent
The reciprocal trigonometric functions
$\sec\theta = \dfrac{1}{\cos\theta} \qquad \operatorname{cosec}\theta = \dfrac{1}{\sin\theta} \qquad \cot\theta = \dfrac{1}{\tan\theta} = \dfrac{\cos\theta}{\sin\theta}$
Which goes with which? Look at the third letter: sec goes with cos, cosec goes with sin, cot goes with tan.

Each reciprocal function is undefined wherever the original function is zero, and the graph has a vertical asymptote there.

FunctionUndefined whenRangePeriod
$y = \sec x$$\cos x = 0$: $x = \tfrac{\pi}{2} + n\pi$$y \leqslant -1$ or $y \geqslant 1$$2\pi$
$y = \operatorname{cosec} x$$\sin x = 0$: $x = n\pi$$y \leqslant -1$ or $y \geqslant 1$$2\pi$
$y = \cot x$$\tan x = 0$: $x = n\pi$all real $y$$\pi$

(Here $n$ is any integer.)

$y = \sec x$ (solid) for $0 \leqslant x \leqslant 2\pi$. Where $\cos x = \pm1$ the two graphs touch; where $\cos x = 0$, $\sec x$ has an asymptote.

Worked Example 1 — Exact values

Find the exact values of $\sec\dfrac{\pi}{3}$, $\operatorname{cosec}\dfrac{5\pi}{4}$ and $\cot\dfrac{\pi}{6}$.

①$\cos\dfrac{\pi}{3} = \dfrac12$, so $\sec\dfrac{\pi}{3} = 2$.
②$\sin\dfrac{5\pi}{4} = -\dfrac{\sqrt2}{2}$, so $\operatorname{cosec}\dfrac{5\pi}{4} = -\dfrac{2}{\sqrt2} = -\sqrt2$.
③$\tan\dfrac{\pi}{6} = \dfrac{1}{\sqrt3}$, so $\cot\dfrac{\pi}{6} = \sqrt3$.
2 Two New Pythagorean Identities

Divide $\sin^2\theta + \cos^2\theta \equiv 1$ by $\cos^2\theta$, and then by $\sin^2\theta$:

Pythagorean identities
$\sin^2\theta + \cos^2\theta \equiv 1$
$\dfrac{\sin^2\theta}{\cos^2\theta} + 1 \equiv \dfrac{1}{\cos^2\theta} \;\Rightarrow\; 1 + \tan^2\theta \equiv \sec^2\theta$
$1 + \dfrac{\cos^2\theta}{\sin^2\theta} \equiv \dfrac{1}{\sin^2\theta} \;\Rightarrow\; 1 + \cot^2\theta \equiv \operatorname{cosec}^2\theta$
When to use them. An equation containing both $\tan^2\theta$ and $\sec\theta$ (or $\cot^2\theta$ and $\operatorname{cosec}\theta$) can be rewritten in terms of a single function, giving a quadratic.
Worked Example 2 — A quadratic in $\sec\theta$

Solve $2\tan^2\theta + \sec\theta = 1$ for $0^\circ \leqslant \theta \leqslant 360^\circ$.

①Replace $\tan^2\theta$ by $\sec^2\theta - 1$: $\;2\sec^2\theta - 2 + \sec\theta = 1$.
②$2\sec^2\theta + \sec\theta - 3 = 0 \Rightarrow (2\sec\theta + 3)(\sec\theta - 1) = 0$.
③$\sec\theta = 1 \Rightarrow \cos\theta = 1 \Rightarrow \theta = 0^\circ, 360^\circ$.
④$\sec\theta = -\tfrac32 \Rightarrow \cos\theta = -\tfrac23 \Rightarrow \theta = 131.8^\circ$ or $360^\circ - 131.8^\circ = 228.2^\circ$.
⑤$\theta = 0^\circ,\ 131.8^\circ,\ 228.2^\circ,\ 360^\circ$.
Worked Example 3 — A quadratic in $\operatorname{cosec} x$

Solve $2\cot^2 x = 7\operatorname{cosec} x - 8$ for $0^\circ < x < 360^\circ$.

①$2(\operatorname{cosec}^2 x - 1) = 7\operatorname{cosec} x - 8 \Rightarrow 2\operatorname{cosec}^2 x - 7\operatorname{cosec} x + 6 = 0$.
②$(2\operatorname{cosec} x - 3)(\operatorname{cosec} x - 2) = 0$.
③$\operatorname{cosec} x = 2 \Rightarrow \sin x = \tfrac12 \Rightarrow x = 30^\circ, 150^\circ$.
④$\operatorname{cosec} x = \tfrac32 \Rightarrow \sin x = \tfrac23 \Rightarrow x = 41.8^\circ, 138.2^\circ$.
Worked Example 4 — Proving an identity

Prove that $\sec\theta - \cos\theta \equiv \sin\theta\tan\theta$.

①LHS $= \dfrac{1}{\cos\theta} - \cos\theta = \dfrac{1 - \cos^2\theta}{\cos\theta}$
②$= \dfrac{\sin^2\theta}{\cos\theta} = \sin\theta \times \dfrac{\sin\theta}{\cos\theta} = \sin\theta\tan\theta = $ RHS $\blacksquare$
Converting everything to $\sin$ and $\cos$ is the most reliable first move when you cannot see a neater route.
3 The Inverse Trigonometric Functions

$\sin x$ is many-to-one, so it has no inverse over its whole domain. Restrict the domain to a section where it is one-to-one and covers every output once, and then it does. The same goes for $\cos$ and $\tan$.

FunctionDomainRangeRestriction of the original
$y = \arcsin x$$-1 \leqslant x \leqslant 1$$-\tfrac{\pi}{2} \leqslant y \leqslant \tfrac{\pi}{2}$$\sin x$ with $-\tfrac{\pi}{2} \leqslant x \leqslant \tfrac{\pi}{2}$
$y = \arccos x$$-1 \leqslant x \leqslant 1$$0 \leqslant y \leqslant \pi$$\cos x$ with $0 \leqslant x \leqslant \pi$
$y = \arctan x$all real $x$$-\tfrac{\pi}{2} < y < \tfrac{\pi}{2}$$\tan x$ with $-\tfrac{\pi}{2} < x < \tfrac{\pi}{2}$

$\arcsin$ and $\arccos$ stop at $x = \pm1$; $\arctan$ continues for all $x$ and approaches the asymptotes $y = \pm\tfrac{\pi}{2}$.

One answer only. $\arcsin\tfrac12$ means the single value $\tfrac{\pi}{6}$ in the range above — not "all the angles whose sine is $\tfrac12$". The notation $\sin^{-1}x$ means the same as $\arcsin x$; it does not mean $\dfrac{1}{\sin x}$, which is $\operatorname{cosec} x$.
Worked Example 5 — Evaluating inverse functions

Find the exact values of $\arcsin\left(-\tfrac12\right)$, $\arccos\left(-\tfrac{\sqrt2}{2}\right)$ and $\arctan\sqrt3$.

①The answer must lie between $-\tfrac{\pi}{2}$ and $\tfrac{\pi}{2}$: $\arcsin\left(-\tfrac12\right) = -\tfrac{\pi}{6}$.
②The answer must lie between $0$ and $\pi$: $\arccos\left(-\tfrac{\sqrt2}{2}\right) = \pi - \tfrac{\pi}{4} = \tfrac{3\pi}{4}$.
③$\arctan\sqrt3 = \tfrac{\pi}{3}$.
Worked Example 6 — A function of an inverse function

Find the exact value of $\sin\left(\arccos\tfrac35\right)$, and show that $\cos(\arcsin x) = \sqrt{1 - x^2}$ for $-1 \leqslant x \leqslant 1$.

①Let $\alpha = \arccos\tfrac35$, so $\cos\alpha = \tfrac35$ with $0 \leqslant \alpha \leqslant \pi$.
②$\sin^2\alpha = 1 - \tfrac{9}{25} = \tfrac{16}{25}$. On $0 \leqslant \alpha \leqslant \pi$, $\sin\alpha \geqslant 0$, so $\sin\alpha = \tfrac45$.
③Let $\beta = \arcsin x$, so $\sin\beta = x$ with $-\tfrac{\pi}{2} \leqslant \beta \leqslant \tfrac{\pi}{2}$.
④$\cos^2\beta = 1 - x^2$, and $\cos\beta \geqslant 0$ in that range, so $\cos(\arcsin x) = \sqrt{1 - x^2}$. $\blacksquare$
The range of the inverse function is what decides the sign of the square root. Always quote it.
4 Quick Reference

Reciprocals

$\sec = \tfrac{1}{\cos}$,  $\operatorname{cosec} = \tfrac{1}{\sin}$,  $\cot = \tfrac{1}{\tan}$

Asymptotes

Where the original function is zero.

Range of sec, cosec

$y \leqslant -1$ or $y \geqslant 1$

Identity 1

$1 + \tan^2\theta \equiv \sec^2\theta$

Identity 2

$1 + \cot^2\theta \equiv \operatorname{cosec}^2\theta$

arcsin

$-1 \leqslant x \leqslant 1$,  $-\tfrac{\pi}{2} \leqslant y \leqslant \tfrac{\pi}{2}$

arccos

$-1 \leqslant x \leqslant 1$,  $0 \leqslant y \leqslant \pi$

arctan

All real $x$,  $-\tfrac{\pi}{2} < y < \tfrac{\pi}{2}$

Notation

$\sin^{-1}x = \arcsin x \neq \operatorname{cosec} x$

5 Practice Questions
Question 1

Find the exact values of $\sec\dfrac{\pi}{4}$, $\operatorname{cosec}\dfrac{5\pi}{6}$ and $\cot\dfrac{2\pi}{3}$.

▶ Show solution

$\cos\tfrac{\pi}{4} = \tfrac{\sqrt2}{2}$, so $\sec\tfrac{\pi}{4} = \tfrac{2}{\sqrt2} = \sqrt2$.

$\sin\tfrac{5\pi}{6} = \tfrac12$, so $\operatorname{cosec}\tfrac{5\pi}{6} = 2$.

$\tan\tfrac{2\pi}{3} = -\sqrt3$, so $\cot\tfrac{2\pi}{3} = -\tfrac{1}{\sqrt3} = -\tfrac{\sqrt3}{3}$.

Question 2

Find the exact values of $\arcsin\dfrac{\sqrt3}{2}$, $\arccos\left(-\dfrac12\right)$ and $\arctan(-1)$.

▶ Show solution

$\arcsin\tfrac{\sqrt3}{2} = \tfrac{\pi}{3}$.

$\arccos\left(-\tfrac12\right) = \pi - \tfrac{\pi}{3} = \tfrac{2\pi}{3}$ (must be between $0$ and $\pi$).

$\arctan(-1) = -\tfrac{\pi}{4}$ (must be between $-\tfrac{\pi}{2}$ and $\tfrac{\pi}{2}$).

Question 3

Solve $\sec x = 2$ for $0 \leqslant x \leqslant 2\pi$.

▶ Show solution

$\cos x = \tfrac12$, so $x = \tfrac{\pi}{3}$ or $x = 2\pi - \tfrac{\pi}{3} = \tfrac{5\pi}{3}$.

Question 4

Given that $\tan\theta = \tfrac34$ and $\pi < \theta < \tfrac{3\pi}{2}$, find the exact values of $\sec\theta$ and $\operatorname{cosec}\theta$.

▶ Show solution

$\sec^2\theta = 1 + \tfrac{9}{16} = \tfrac{25}{16}$. In the third quadrant $\cos\theta < 0$, so $\sec\theta = -\tfrac54$.

$\operatorname{cosec}^2\theta = 1 + \cot^2\theta = 1 + \tfrac{16}{9} = \tfrac{25}{9}$. $\sin\theta < 0$ there, so $\operatorname{cosec}\theta = -\tfrac53$.

Question 5

Prove that $\sec^2\theta + \operatorname{cosec}^2\theta \equiv \sec^2\theta\operatorname{cosec}^2\theta$.

▶ Show solution

LHS $= \dfrac{1}{\cos^2\theta} + \dfrac{1}{\sin^2\theta} = \dfrac{\sin^2\theta + \cos^2\theta}{\sin^2\theta\cos^2\theta} = \dfrac{1}{\sin^2\theta\cos^2\theta}$

$= \sec^2\theta\operatorname{cosec}^2\theta = $ RHS $\blacksquare$

Question 6

Solve $\sec^2\theta = 3 + \tan\theta$ for $0 \leqslant \theta \leqslant 2\pi$, giving answers to $3$ significant figures where they are not exact.

▶ Show solution

$1 + \tan^2\theta = 3 + \tan\theta \Rightarrow \tan^2\theta - \tan\theta - 2 = 0 \Rightarrow (\tan\theta - 2)(\tan\theta + 1) = 0$.

$\tan\theta = -1$: $\theta = \tfrac{3\pi}{4}, \tfrac{7\pi}{4}$.

$\tan\theta = 2$: $\theta = 1.11$, and $1.107 + \pi = 4.25$.

$\theta = 1.11,\ \tfrac{3\pi}{4},\ 4.25,\ \tfrac{7\pi}{4}$.

Question 7

Find the exact values of $\sin\left(\arccos\dfrac{5}{13}\right)$ and $\tan\left(\arcsin\left(-\dfrac35\right)\right)$.

▶ Show solution

Let $\alpha = \arccos\tfrac{5}{13}$, $0 \leqslant \alpha \leqslant \pi$, so $\sin\alpha \geqslant 0$: $\sin\alpha = \sqrt{1 - \tfrac{25}{169}} = \tfrac{12}{13}$.

Let $\beta = \arcsin\left(-\tfrac35\right)$, so $-\tfrac{\pi}{2} \leqslant \beta < 0$ and $\cos\beta = \tfrac45$ (positive).

$\tan\beta = \dfrac{-3/5}{4/5} = -\tfrac34$.

Question 8

Solve $3\operatorname{cosec}^2 x - 5\cot x - 5 = 0$ for $0^\circ < x < 180^\circ$.

▶ Show solution

$3(1 + \cot^2 x) - 5\cot x - 5 = 0 \Rightarrow 3\cot^2 x - 5\cot x - 2 = 0$.

$(3\cot x + 1)(\cot x - 2) = 0$.

$\cot x = 2 \Rightarrow \tan x = \tfrac12 \Rightarrow x = 26.6^\circ$.

$\cot x = -\tfrac13 \Rightarrow \tan x = -3 \Rightarrow x = 180^\circ - 71.6^\circ = 108.4^\circ$.

Question 9

Prove that $\arcsin x + \arccos x = \dfrac{\pi}{2}$ for $-1 \leqslant x \leqslant 1$.

▶ Show solution

Let $\alpha = \arcsin x$, so $\sin\alpha = x$ and $-\tfrac{\pi}{2} \leqslant \alpha \leqslant \tfrac{\pi}{2}$.

Then $\cos\left(\tfrac{\pi}{2} - \alpha\right) = \sin\alpha = x$, and $0 \leqslant \tfrac{\pi}{2} - \alpha \leqslant \pi$.

That is exactly the range of $\arccos$, so $\arccos x = \tfrac{\pi}{2} - \alpha$.

Hence $\arcsin x + \arccos x = \alpha + \tfrac{\pi}{2} - \alpha = \tfrac{\pi}{2}$. $\blacksquare$

Question 10

The function g is defined by $\mathrm{g}(x) = 4 - 3\arccos\left(\dfrac{x}{2}\right)$, for $-2 \leqslant x \leqslant 2$.

(a) Find the range of g.   (b) Find the exact value of $\mathrm{g}(1)$.   (c) Solve $\mathrm{g}(x) = 4 - \dfrac{\pi}{2}$.   (d) Find $\mathrm{g}^{-1}(x)$ and state its domain.

▶ Show solution

(a) $\arccos\left(\tfrac{x}{2}\right)$ takes every value from $0$ to $\pi$. So $\mathrm{g}(x)$ takes every value from $4 - 3\pi$ to $4$:  $4 - 3\pi \leqslant \mathrm{g}(x) \leqslant 4$.

(b) $\mathrm{g}(1) = 4 - 3\arccos\tfrac12 = 4 - 3 \times \tfrac{\pi}{3} = 4 - \pi$.

(c) $3\arccos\left(\tfrac{x}{2}\right) = \tfrac{\pi}{2} \Rightarrow \arccos\left(\tfrac{x}{2}\right) = \tfrac{\pi}{6} \Rightarrow \tfrac{x}{2} = \tfrac{\sqrt3}{2} \Rightarrow x = \sqrt3$.

(d) $y = 4 - 3\arccos\left(\tfrac{x}{2}\right) \Rightarrow \arccos\left(\tfrac{x}{2}\right) = \dfrac{4 - y}{3} \Rightarrow x = 2\cos\left(\dfrac{4 - y}{3}\right)$.

$\mathrm{g}^{-1}(x) = 2\cos\left(\dfrac{4 - x}{3}\right)$, with domain $4 - 3\pi \leqslant x \leqslant 4$ (the range of g).
