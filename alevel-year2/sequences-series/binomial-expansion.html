1 Extending the Binomial Expansion

In Year 1 you expanded $(a + b)^n$ for a positive whole number $n$, using $^nC_r$ or Pascal's triangle (see The Binomial Expansion). That expansion always stops after $n + 1$ terms. Now $n$ can be negative or a fraction.

The general binomial expansion — for any rational $n$, valid for $|x| < 1$
$(1 + x)^n = 1 + nx + \dfrac{n(n-1)}{2!}x^2 + \dfrac{n(n-1)(n-2)}{3!}x^3 + \cdots$
Two big differences from Year 1.
1. When $n$ is not a positive integer, no factor $(n - k)$ is ever zero, so the expansion never stops: it is an infinite series.
2. An infinite series only adds up to the right answer if it converges, so the expansion is only valid for $|x| < 1$.
Building each coefficient. Each new coefficient is the previous one times the next factor, divided by the next whole number: $1$, then $\times\dfrac{n}{1}$, then $\times\dfrac{n-1}{2}$, then $\times\dfrac{n-2}{3}$, and so on.
Worked Example 1 — A negative power

Expand $(1 + x)^{-1}$ in ascending powers of $x$ up to $x^3$, and state the range of validity.

①$n = -1$:  $1 + (-1)x + \dfrac{(-1)(-2)}{2}x^2 + \dfrac{(-1)(-2)(-3)}{6}x^3$
②$= 1 - x + x^2 - x^3 + \cdots$  for $|x| < 1$.
This is the geometric series $1 + r + r^2 + \cdots$ with $r = -x$, which has sum $\dfrac{1}{1 - (-x)} = \dfrac{1}{1+x}$. The validity condition $|x| < 1$ is exactly the convergence condition $|r| < 1$.
2 Expanding $(1 + bx)^n$

Replace every $x$ in the formula by $bx$, in a bracket. The expansion is valid when $|bx| < 1$, i.e. $|x| < \dfrac{1}{|b|}$.

Worked Example 2 — A fractional power

Expand $\sqrt{1 - 2x}$ up to the term in $x^3$, and state the values of $x$ for which it is valid.

①$(1 - 2x)^{1/2}$, with $n = \tfrac12$ and "$x$" $= -2x$.
②$1 + \tfrac12(-2x) + \dfrac{\frac12\left(-\frac12\right)}{2}(-2x)^2 + \dfrac{\frac12\left(-\frac12\right)\left(-\frac32\right)}{6}(-2x)^3$
③$= 1 - x + \left(-\tfrac18\right)(4x^2) + \left(\tfrac{1}{16}\right)(-8x^3)$
④$= 1 - x - \tfrac12 x^2 - \tfrac12 x^3 + \cdots$
⑤Valid for $|-2x| < 1$, i.e. $|x| < \tfrac12$.
Bracket the whole term. $(-2x)^2 = 4x^2$ and $(-2x)^3 = -8x^3$. Writing $-2x^2$ is the most common error in these questions.
Worked Example 3 — Finding unknowns

In the expansion of $(1 + ax)^n$ the coefficient of $x$ is $-6$ and the coefficient of $x^2$ is $27$. Find $a$ and $n$, and the coefficient of $x^3$.

①$na = -6$ and $\dfrac{n(n-1)}{2}a^2 = 27$, so $n(n-1)a^2 = 54$.
②Squaring the first: $n^2a^2 = 36$. Divide: $\dfrac{n - 1}{n} = \dfrac{54}{36} = \dfrac32$.
③$2n - 2 = 3n \Rightarrow n = -2$, and then $a = -6 \div -2 = 3$.
④Coefficient of $x^3$: $\dfrac{(-2)(-3)(-4)}{6} \times 3^3 = -4 \times 27 = -108$.
3 Expanding $(a + bx)^n$

The formula needs a $1$ at the front of the bracket. So take out a factor of $a$ first — remembering that it comes out raised to the power $n$.

Take out the factor first
$(a + bx)^n = a^n\left(1 + \dfrac{b}{a}x\right)^n$,  valid for $\left|\dfrac{bx}{a}\right| < 1$, i.e. $|x| < \left|\dfrac{a}{b}\right|$
Worked Example 4 — A bracket not starting with 1

Find the first four terms of the expansion of $\dfrac{1}{(2 + 3x)^2}$, and state the range of validity.

①$(2 + 3x)^{-2} = 2^{-2}\left(1 + \tfrac32 x\right)^{-2} = \tfrac14\left(1 + \tfrac32 x\right)^{-2}$
②Coefficients for $n = -2$: $1,\; -2,\; \dfrac{(-2)(-3)}{2} = 3,\; \dfrac{(-2)(-3)(-4)}{6} = -4$.
③$\left(1 + \tfrac32 x\right)^{-2} = 1 - 3x + 3\cdot\tfrac94 x^2 - 4\cdot\tfrac{27}{8}x^3 = 1 - 3x + \tfrac{27}{4}x^2 - \tfrac{27}{2}x^3$
④Multiply by $\tfrac14$: $\;\tfrac14 - \tfrac34 x + \tfrac{27}{16}x^2 - \tfrac{27}{8}x^3 + \cdots$
⑤Valid for $\left|\tfrac32 x\right| < 1$, i.e. $|x| < \tfrac23$.
The factor is $2^{-2} = \tfrac14$, not $2$. Forgetting to raise $a$ to the power $n$ loses most of the marks.
4 Approximations

When $|x|$ is small, the powers $x^2, x^3, \ldots$ are tiny, so the first few terms give an excellent approximation. Choose a value of $x$ that is inside the range of validity and as small as possible.

Worked Example 5 — Approximating $\sqrt{2}$

Use the expansion of $\sqrt{1 - 2x}$ from Worked Example 2, with $x = 0.01$, to find an approximation for $\sqrt{2}$.

①$x = 0.01$ is inside $|x| < \tfrac12$ ✓.  $\sqrt{1 - 0.02} = \sqrt{0.98}$.
②$\sqrt{0.98} \approx 1 - 0.01 - 0.00005 - 0.0000005 = 0.9899495$
③$\sqrt{0.98} = \sqrt{\dfrac{98}{100}} = \dfrac{7\sqrt2}{10}$, so $\sqrt2 = \dfrac{10}{7}\sqrt{0.98}$.
④$\sqrt2 \approx \dfrac{10}{7} \times 0.9899495 = 1.4142136$ (to 7 d.p.)
The true value is $1.41421356\ldots$ — four terms with $x = 0.01$ give $7$ correct decimal places.
Outside the range the answer is nonsense. Putting $x = 1$ into $1 - x - \tfrac12x^2 - \tfrac12x^3$ to estimate $\sqrt{-1}$ gives $-1$, which is meaningless. Always check validity before substituting.
5 Products and Partial Fractions

Expand each bracket separately, then multiply out, keeping only the powers you need. For a sum of fractions, use partial fractions first.

Validity of a combined expansion
Valid only where every separate expansion is valid — take the narrower range
Worked Example 6 — A quotient

Expand $\dfrac{1 + x}{1 - 2x}$ up to $x^3$.

①$(1 - 2x)^{-1} = 1 + 2x + 4x^2 + 8x^3 + \cdots$ for $|x| < \tfrac12$.
②$(1 + x)(1 + 2x + 4x^2 + 8x^3) = 1 + 2x + 4x^2 + 8x^3 + x + 2x^2 + 4x^3 + \cdots$
③$= 1 + 3x + 6x^2 + 12x^3 + \cdots$  for $|x| < \tfrac12$.
Worked Example 7 — Using partial fractions

(a) Express $\dfrac{4 - 5x}{(1 + x)(2 - x)}$ in partial fractions. (b) Hence expand it up to $x^3$ and state the range of validity.

①$4 - 5x \equiv A(2 - x) + B(1 + x)$.
②$x = -1$: $9 = 3A$, $A = 3$.  $x = 2$: $-6 = 3B$, $B = -2$.
③$\dfrac{4 - 5x}{(1 + x)(2 - x)} \equiv \dfrac{3}{1 + x} - \dfrac{2}{2 - x}$
④$3(1 + x)^{-1} = 3 - 3x + 3x^2 - 3x^3 + \cdots$  for $|x| < 1$.
⑤$2(2 - x)^{-1} = 2 \cdot \tfrac12\left(1 - \tfrac{x}{2}\right)^{-1} = 1 + \tfrac12 x + \tfrac14 x^2 + \tfrac18 x^3 + \cdots$  for $|x| < 2$.
⑥Subtract: $2 - \tfrac72 x + \tfrac{11}{4}x^2 - \tfrac{25}{8}x^3 + \cdots$
⑦Valid where both are valid: $|x| < 1$.
6 Quick Reference

General expansion

$(1+x)^n = 1 + nx + \tfrac{n(n-1)}{2!}x^2 + \cdots$

Validity

$(1+bx)^n$: valid for $|bx| < 1$.

Positive integer $n$

Finite, valid for all $x$.

$(a+bx)^n$

Take out $a^n$: $a^n(1 + \tfrac{b}{a}x)^n$.

Brackets

$(-2x)^2 = 4x^2$, $(-2x)^3 = -8x^3$.

$(1+x)^{-1}$

$1 - x + x^2 - x^3 + \cdots$

$(1-x)^{-1}$

$1 + x + x^2 + x^3 + \cdots$

Combined

Take the narrowest range of validity.

Approximating

Pick a small $x$ inside the valid range.

7 Practice Questions
Question 1

Expand $(1 + x)^{-3}$ up to $x^3$.

▶ Show solution

$1 + (-3)x + \dfrac{(-3)(-4)}{2}x^2 + \dfrac{(-3)(-4)(-5)}{6}x^3$

$= 1 - 3x + 6x^2 - 10x^3 + \cdots$, valid for $|x| < 1$.

Question 2

Expand $\sqrt{1 + 4x}$ up to $x^3$, stating the range of validity.

▶ Show solution

$1 + \tfrac12(4x) + \left(-\tfrac18\right)(4x)^2 + \tfrac{1}{16}(4x)^3$

$= 1 + 2x - 2x^2 + 4x^3 + \cdots$, valid for $|4x| < 1$, i.e. $|x| < \tfrac14$.

Question 3

Find the first three terms of the expansion of $\dfrac{1}{(2 - x)^2}$ and of the term in $x^3$, and state the range of validity.

▶ Show solution

$(2 - x)^{-2} = \tfrac14\left(1 - \tfrac{x}{2}\right)^{-2}$.

$\left(1 - \tfrac{x}{2}\right)^{-2} = 1 - 2\left(-\tfrac{x}{2}\right) + 3\left(\tfrac{x^2}{4}\right) - 4\left(-\tfrac{x^3}{8}\right) = 1 + x + \tfrac34x^2 + \tfrac12x^3$

So $\dfrac{1}{(2-x)^2} = \tfrac14 + \tfrac14x + \tfrac{3}{16}x^2 + \tfrac18x^3 + \cdots$, valid for $|x| < 2$.

Question 4

State, with a reason, the range of $x$ for which each expansion is valid: (a) $(3 - 2x)^{-1/2}$   (b) $(1 + 5x)^{4}$.

▶ Show solution

(a) $(3 - 2x)^{-1/2} = 3^{-1/2}\left(1 - \tfrac23x\right)^{-1/2}$, valid for $\left|\tfrac23x\right| < 1$, i.e. $|x| < \tfrac32$.

(b) The power $4$ is a positive integer, so the expansion has only five terms and is exact: valid for all $x$.

Question 5

Expand $\sqrt[3]{8 - x}$ up to $x^2$. Use your answer with a suitable value of $x$ to estimate $\sqrt[3]{7.9}$ to $6$ decimal places.

▶ Show solution

$(8 - x)^{1/3} = 8^{1/3}\left(1 - \tfrac{x}{8}\right)^{1/3} = 2\left[1 + \tfrac13\left(-\tfrac{x}{8}\right) + \dfrac{\frac13\left(-\frac23\right)}{2}\left(-\tfrac{x}{8}\right)^2\right]$

$= 2\left[1 - \tfrac{x}{24} - \tfrac{x^2}{576}\right] = 2 - \tfrac{x}{12} - \tfrac{x^2}{288} + \cdots$, valid for $|x| < 8$.

$x = 0.1$: $2 - 0.0083333 - 0.0000347 = 1.991632$ (6 d.p.).

(Calculator: $1.9916317\ldots$ — correct to $6$ d.p.)

Question 6

In the expansion of $(1 + kx)^{-1/2}$, the coefficient of $x^2$ is $24$ and the coefficient of $x$ is positive. Find $k$, the coefficient of $x$, and the range of validity.

▶ Show solution

Coefficient of $x^2$: $\dfrac{\left(-\frac12\right)\left(-\frac32\right)}{2}k^2 = \tfrac38k^2 = 24$, so $k^2 = 64$ and $k = \pm 8$.

Coefficient of $x$: $-\tfrac12k$. This is positive only if $k = -8$, giving coefficient $4$.

$(1 - 8x)^{-1/2}$ is valid for $|8x| < 1$, i.e. $|x| < \tfrac18$.

Question 7

Show that $\sqrt{\dfrac{1 + x}{1 - x}} \approx 1 + x + \tfrac12x^2$ for small $x$. By substituting $x = 0.1$, find an approximation for $\sqrt{11}$.

▶ Show solution

$(1 + x)^{1/2} = 1 + \tfrac12x - \tfrac18x^2 + \cdots$ and $(1 - x)^{-1/2} = 1 + \tfrac12x + \tfrac38x^2 + \cdots$

Product: $1 + \tfrac12x + \tfrac38x^2 + \tfrac12x + \tfrac14x^2 - \tfrac18x^2 = 1 + x + \tfrac12x^2$ ✓ (valid for $|x| < 1$).

$x = 0.1$: $\sqrt{\dfrac{1.1}{0.9}} = \sqrt{\dfrac{11}{9}} = \dfrac{\sqrt{11}}{3} \approx 1 + 0.1 + 0.005 = 1.105$.

$\sqrt{11} \approx 3.315$ (true value $3.3166\ldots$).

Question 8

Expand $(1 + x)(1 - x)^{-1}$ up to $x^3$, and hence write down the coefficient of $x^r$ for $r \geqslant 1$.

▶ Show solution

$(1 - x)^{-1} = 1 + x + x^2 + x^3 + \cdots$

$(1 + x)(1 + x + x^2 + x^3) = 1 + 2x + 2x^2 + 2x^3 + \cdots$, valid for $|x| < 1$.

Every power $x^r$ with $r \geqslant 1$ arises from $1 \cdot x^r + x \cdot x^{r-1}$, so its coefficient is $2$.

Question 9

(a) Express $\dfrac{1 + 5x}{(1 - x)(1 + 2x)}$ in partial fractions. (b) Hence find its expansion up to $x^3$, and state the range of validity.

▶ Show solution

(a) $1 + 5x \equiv A(1 + 2x) + B(1 - x)$.

$x = 1$: $6 = 3A$, $A = 2$.  $x = -\tfrac12$: $-\tfrac32 = \tfrac32B$, $B = -1$.

$\dfrac{2}{1 - x} - \dfrac{1}{1 + 2x}$

(b) $2(1 - x)^{-1} = 2 + 2x + 2x^2 + 2x^3$ for $|x| < 1$.

$(1 + 2x)^{-1} = 1 - 2x + 4x^2 - 8x^3$ for $|x| < \tfrac12$.

Subtract: $1 + 4x - 2x^2 + 10x^3 + \cdots$, valid for $|x| < \tfrac12$.

Question 10

(a) Show that $\dfrac{1}{\sqrt{4 - x}} = \dfrac12 + \dfrac{x}{16} + \dfrac{3x^2}{256} + \cdots$ and state the range of validity.

(b) Hence show that $\dfrac{2 + x}{\sqrt{4 - x}} \approx 1 + \dfrac58x + \dfrac{11}{128}x^2$.

(c) By substituting $x = 0.04$, show that $\dfrac{3.4}{\sqrt{11}} \approx 1.0251375$, and hence find an approximation for $\sqrt{11}$, giving your answer to $6$ decimal places.

▶ Show solution

(a) $(4 - x)^{-1/2} = 4^{-1/2}\left(1 - \tfrac{x}{4}\right)^{-1/2} = \tfrac12\left[1 + \left(-\tfrac12\right)\left(-\tfrac{x}{4}\right) + \dfrac{\left(-\frac12\right)\left(-\frac32\right)}{2}\left(-\tfrac{x}{4}\right)^2\right]$

$= \tfrac12\left[1 + \tfrac{x}{8} + \tfrac38\cdot\tfrac{x^2}{16}\right] = \tfrac12 + \tfrac{x}{16} + \tfrac{3x^2}{256}$ ✓, valid for $|x| < 4$.

(b) $(2 + x)\left(\tfrac12 + \tfrac{x}{16} + \tfrac{3x^2}{256}\right) = 1 + \tfrac{x}{8} + \tfrac{3x^2}{128} + \tfrac{x}{2} + \tfrac{x^2}{16} + \cdots$

$= 1 + \tfrac58x + \left(\tfrac{3}{128} + \tfrac{8}{128}\right)x^2 = 1 + \tfrac58x + \tfrac{11}{128}x^2$ ✓

(c) $x = 0.04$ is within $|x| < 4$. LHS $= \dfrac{2.04}{\sqrt{3.96}}$, and $\sqrt{3.96} = \dfrac{\sqrt{396}}{10} = \dfrac{6\sqrt{11}}{10}$, so LHS $= \dfrac{2.04 \times 10}{6\sqrt{11}} = \dfrac{3.4}{\sqrt{11}}$.

RHS $= 1 + 0.025 + \dfrac{11 \times 0.0016}{128} = 1 + 0.025 + 0.0001375 = 1.0251375$ ✓

$\sqrt{11} \approx \dfrac{3.4}{1.0251375} = 3.316628$ (6 d.p.). The true value is $3.316625\ldots$, so the error is only about $3 \times 10^{-6}$.
