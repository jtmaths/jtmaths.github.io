1 Two Ways to Define a Sequence
A sequence is an ordered list of numbers $u_1, u_2, u_3, \ldots$ called terms. The subscript tells you the position. A rule is needed to generate the terms, and at A Level there are two kinds of rule.
Type of ruleWhat it gives youExample
$n$th term (position-to-term)Any term directly from its position $n$.$u_n = 3n^2 - 2$
Recurrence relation (term-to-term)Each term from the one before, plus a starting value.$u_{n+1} = 2u_n - 3,\; u_1 = 5$
Worked Example 1 — Using an $n$th term

A sequence has $n$th term $u_n = 3n^2 - 2$. Write down the first three terms, and find which term is equal to $145$.

①$u_1 = 3 - 2 = 1$,  $u_2 = 12 - 2 = 10$,  $u_3 = 27 - 2 = 25$.
②Set $3n^2 - 2 = 145$, so $3n^2 = 147$ and $n^2 = 49$.
③$n = 7$ (reject $n = -7$, since a position must be a positive integer).
④$145$ is the $7$th term.
Is $100$ a term? $3n^2 = 102$ gives $n^2 = 34$, which is not a perfect square. So $100$ is not in the sequence — a non-integer $n$ is the proof.
2 Recurrence Relations
A recurrence relation
$u_{n+1} = \mathrm{f}(u_n)$  together with a first term such as $u_1 = a$

The same rule with a different starting value gives a completely different sequence, so the first term is part of the definition. Some textbooks write $x_{n+1} = \mathrm{f}(x_n)$; the letter does not matter.

Worked Example 2 — Generating terms

$u_{n+1} = 2u_n - 3$ with $u_1 = 5$. Find $u_2$, $u_3$ and $u_4$.

①$u_2 = 2(5) - 3 = 7$
②$u_3 = 2(7) - 3 = 11$
③$u_4 = 2(11) - 3 = 19$
On a calculator: type $5$, press =, then type $2\times\text{Ans} - 3$ and press = repeatedly. Each press gives the next term.
Worked Example 3 — Finding an unknown constant

A sequence is defined by $u_{n+1} = k u_n + 4$, $u_1 = 2$. Given that $u_3 = 20$, find the possible values of $k$.

①$u_2 = 2k + 4$
②$u_3 = k(2k + 4) + 4 = 2k^2 + 4k + 4$
③$2k^2 + 4k + 4 = 20 \;\Rightarrow\; k^2 + 2k - 8 = 0$
④$(k + 4)(k - 2) = 0$, so $k = 2$ or $k = -4$.
⑤Check $k = -4$: $u_2 = -4$, $u_3 = -4(-4) + 4 = 20$ ✓
Limits. If a sequence defined by $u_{n+1} = \mathrm{f}(u_n)$ converges to a limit $L$, then for large $n$ both $u_n$ and $u_{n+1}$ are close to $L$. So $L$ must satisfy $L = \mathrm{f}(L)$. This gives the value of the limit — but it does not prove that the sequence actually converges.
3 Increasing, Decreasing and Periodic Sequences
WordDefinitionExample
Increasing$u_{n+1} > u_n$ for all $n$$2, 5, 8, 11, \ldots$
Decreasing$u_{n+1} < u_n$ for all $n$$1, \tfrac12, \tfrac14, \tfrac18, \ldots$
PeriodicThe terms repeat: $u_{n+k} = u_n$ for all $n$$2, -1, \tfrac12, 2, -1, \tfrac12, \ldots$

The smallest such $k$ is the order (or period) of a periodic sequence. A sequence can also be none of these, for example $1, -2, 3, -4, \ldots$ (it oscillates but never repeats).

To prove a sequence is increasing
Show that $u_{n+1} - u_n > 0$ for every $n \geqslant 1$
Worked Example 4 — Proving a sequence is increasing

Prove that the sequence with $n$th term $u_n = \dfrac{n}{n+1}$ is increasing.

①$u_{n+1} - u_n = \dfrac{n+1}{n+2} - \dfrac{n}{n+1}$
②$= \dfrac{(n+1)^2 - n(n+2)}{(n+1)(n+2)} = \dfrac{n^2 + 2n + 1 - n^2 - 2n}{(n+1)(n+2)}$
③$= \dfrac{1}{(n+1)(n+2)}$
④For $n \geqslant 1$ the denominator is positive, so $u_{n+1} - u_n > 0$ and the sequence is increasing. $\blacksquare$
Writing out $\tfrac12, \tfrac23, \tfrac34, \ldots$ shows the pattern, but checking a few terms is not a proof. You must deal with a general $n$.
Worked Example 5 — A periodic sequence

$u_{n+1} = \dfrac{1}{1 - u_n}$ with $u_1 = 2$. Show that the sequence is periodic, state its order, and find $\displaystyle\sum_{r=1}^{100} u_r$.

①$u_2 = \dfrac{1}{1-2} = -1$,  $u_3 = \dfrac{1}{1-(-1)} = \dfrac12$,  $u_4 = \dfrac{1}{1 - \frac12} = 2$.
②$u_4 = u_1$, and each term depends only on the one before, so the pattern $2, -1, \tfrac12$ repeats for ever. The sequence is periodic with order 3.
③One cycle sums to $2 - 1 + \tfrac12 = \tfrac32$.
④$100 = 3 \times 33 + 1$: thirty-three full cycles, then one more term $u_{100} = u_1 = 2$.
⑤$\displaystyle\sum_{r=1}^{100} u_r = 33 \times \tfrac32 + 2 = 49.5 + 2 = 51.5$
Trig sequences are often periodic. $u_n = \cos\left(\dfrac{n\pi}{2}\right)$ gives $0, -1, 0, 1, 0, -1, \ldots$ — order $4$, because $\cos$ repeats every $2\pi$ and each step adds $\tfrac{\pi}{2}$.
4 Sigma Notation
Sigma notation
$\displaystyle\sum_{r=1}^{n} u_r = u_1 + u_2 + u_3 + \cdots + u_n$

$\Sigma$ (capital sigma) means "add up". The letter $r$ is a dummy variable: it takes every whole-number value from the bottom limit to the top limit, inclusive.

Counting terms. $\displaystyle\sum_{r=4}^{20}$ has $20 - 4 + 1 = 17$ terms, not $16$. The number of terms from $r = a$ to $r = b$ is $b - a + 1$.
Worked Example 6 — Evaluating a short sum

Evaluate $\displaystyle\sum_{r=1}^{5} (2r + 1)$.

①$r = 1, 2, 3, 4, 5$ give $3, 5, 7, 9, 11$.
②Sum $= 3 + 5 + 7 + 9 + 11 = 35$.
Useful standard results
$\displaystyle\sum_{r=1}^{n} 1 = n$     $\displaystyle\sum_{r=1}^{n} r = \tfrac12 n(n+1)$     $\displaystyle\sum_{r=1}^{n} (a u_r + b v_r) = a\sum_{r=1}^{n} u_r + b\sum_{r=1}^{n} v_r$

The formula for $\sum r$ is proved on the arithmetic series page.

Worked Example 7 — Splitting a sum

Evaluate $\displaystyle\sum_{r=1}^{20} (3r - 2)$.

①$\displaystyle\sum_{r=1}^{20} (3r - 2) = 3\sum_{r=1}^{20} r - \sum_{r=1}^{20} 2$
②$= 3 \times \tfrac12(20)(21) - 2 \times 20$
③$= 630 - 40 = 590$
$\displaystyle\sum_{r=1}^{20} 2$ is $2 + 2 + \cdots + 2$ with twenty terms, which is $40$ — not $2$.
Worked Example 8 — A sum that does not start at 1

Evaluate $\displaystyle\sum_{r=11}^{30} r$.

①Take everything up to $30$ and remove everything up to $10$:
②$\displaystyle\sum_{r=11}^{30} r = \sum_{r=1}^{30} r - \sum_{r=1}^{10} r$
③$= \tfrac12(30)(31) - \tfrac12(10)(11) = 465 - 55 = 410$
Subtract the sum up to $10$, not up to $11$ — the term $r = 11$ must stay in.
Worked Example 9 — Writing a sum in sigma notation

Write $4 + 7 + 10 + \cdots + 61$ using sigma notation.

①The terms go up by $3$, starting at $4$, so $u_r = 3r + 1$.
②Last term: $3r + 1 = 61$ gives $r = 20$.
③$\displaystyle 4 + 7 + \cdots + 61 = \sum_{r=1}^{20} (3r + 1)$
There is more than one correct answer: $\displaystyle\sum_{r=0}^{19}(3r + 4)$ describes exactly the same sum.
5 Quick Reference

$n$th term

Position to term: substitute $n$ directly.

Recurrence

$u_{n+1} = \mathrm{f}(u_n)$ plus a first term.

Is it a term?

Solve $u_n = $ value; it is a term only if $n$ is a positive integer.

Increasing

Prove $u_{n+1} - u_n > 0$ for all $n$.

Periodic

$u_{n+k} = u_n$; order $k$ is the shortest repeat.

Limit

If it converges, $L = \mathrm{f}(L)$.

Counting terms

$r = a$ to $r = b$ has $b - a + 1$ terms.

Standard sums

$\sum 1 = n$,  $\sum r = \tfrac12 n(n+1)$.

Not from 1

$\sum_{a}^{b} = \sum_{1}^{b} - \sum_{1}^{a-1}$.

6 Practice Questions
Question 1

A sequence has $n$th term $u_n = 5n - 3$. Find $u_1$ and $u_{10}$, and find which term equals $92$.

▶ Show solution

$u_1 = 5 - 3 = 2$ and $u_{10} = 50 - 3 = 47$.

$5n - 3 = 92 \Rightarrow 5n = 95 \Rightarrow n = 19$. So $92$ is the $19$th term.

Question 2

$u_{n+1} = 3u_n - 1$ with $u_1 = 2$. Find $u_2$, $u_3$ and $u_4$.

▶ Show solution

$u_2 = 3(2) - 1 = 5$

$u_3 = 3(5) - 1 = 14$

$u_4 = 3(14) - 1 = 41$

Question 3

Write $2 + 5 + 8 + \cdots + 59$ in sigma notation.

▶ Show solution

The terms increase by $3$ from $2$, so $u_r = 3r - 1$.

$3r - 1 = 59 \Rightarrow r = 20$.

$\displaystyle 2 + 5 + \cdots + 59 = \sum_{r=1}^{20} (3r - 1)$

Question 4

Evaluate $\displaystyle\sum_{r=1}^{4} 2^r$ and $\displaystyle\sum_{r=0}^{3} (r^2 + 1)$.

▶ Show solution

$\displaystyle\sum_{r=1}^{4} 2^r = 2 + 4 + 8 + 16 = 30$

$\displaystyle\sum_{r=0}^{3} (r^2 + 1) = 1 + 2 + 5 + 10 = 18$ (note that $r = 0$ is included, giving four terms).

Question 5

Is the sequence $u_n = n^2 - 6n$ increasing, decreasing, or neither? Justify your answer.

▶ Show solution

$u_{n+1} - u_n = (n+1)^2 - 6(n+1) - n^2 + 6n = 2n - 5$.

This is negative for $n = 1, 2$ and positive for $n \geqslant 3$.

The terms are $-5, -8, -9, -8, -5, \ldots$: they fall then rise, so the sequence is neither increasing nor decreasing.

Question 6

Find $a$ and $b$ given that the sequence $u_{n+1} = a u_n + b$ has $u_1 = 4$, $u_2 = 7$ and $u_3 = 13$. Hence find $u_4$.

▶ Show solution

$u_2$: $4a + b = 7$.  $u_3$: $7a + b = 13$.

Subtract: $3a = 6$, so $a = 2$ and $b = 7 - 8 = -1$.

$u_4 = 2(13) - 1 = 25$.

Question 7

$u_{n+1} = -\dfrac{1}{u_n}$ with $u_1 = 3$. Show that the sequence is periodic, state its order, and find $\displaystyle\sum_{r=1}^{25} u_r$.

▶ Show solution

$u_2 = -\tfrac13$, $u_3 = -\dfrac{1}{-\frac13} = 3 = u_1$. The sequence is periodic with order $2$.

Each pair sums to $3 - \tfrac13 = \tfrac83$.

$25 = 2 \times 12 + 1$: twelve pairs, then $u_{25} = u_1 = 3$.

$\displaystyle\sum_{r=1}^{25} u_r = 12 \times \tfrac83 + 3 = 32 + 3 = 35$

Question 8

Evaluate $\displaystyle\sum_{r=10}^{25} (2r - 1)$.

▶ Show solution

$\displaystyle\sum_{r=1}^{n} (2r - 1) = 2 \times \tfrac12 n(n+1) - n = n^2$.

$\displaystyle\sum_{r=10}^{25} (2r-1) = \sum_{r=1}^{25} (2r-1) - \sum_{r=1}^{9} (2r-1) = 625 - 81 = 544$

Question 9

Show that $\displaystyle\sum_{r=1}^{n} (4r + 3) = 2n^2 + 5n$, and hence find $n$ such that $\displaystyle\sum_{r=1}^{n} (4r + 3) = 250$.

▶ Show solution

$\displaystyle\sum_{r=1}^{n} (4r + 3) = 4 \times \tfrac12 n(n+1) + 3n = 2n^2 + 2n + 3n = 2n^2 + 5n$ ✓

$2n^2 + 5n - 250 = 0 \Rightarrow (2n + 25)(n - 10) = 0$.

$n$ must be a positive integer, so $n = 10$.

Question 10

A lake is stocked with fish. Each year $20\%$ of the fish are caught, and then $300$ new fish are added. At the start there are $1000$ fish. Let $P_n$ be the number of fish after $n$ years.

(a) Explain why $P_{n+1} = 0.8P_n + 300$, with $P_0 = 1000$.   (b) Find $P_1$, $P_2$ and $P_3$.   (c) Given that the sequence converges, find its limit.   (d) Verify that $P_n = 1500 - 500(0.8)^n$ satisfies the recurrence relation, and hence find the first year in which the population exceeds $1450$.

▶ Show solution

(a) Losing $20\%$ leaves $0.8P_n$; adding $300$ gives $0.8P_n + 300$.

(b) $P_1 = 800 + 300 = 1100$,  $P_2 = 880 + 300 = 1180$,  $P_3 = 944 + 300 = 1244$.

(c) $L = 0.8L + 300 \Rightarrow 0.2L = 300 \Rightarrow L = 1500$ fish.

(d) $P_0 = 1500 - 500 = 1000$ ✓.  $0.8P_n + 300 = 1200 - 400(0.8)^n + 300 = 1500 - 500(0.8)^{n+1} = P_{n+1}$ ✓

Need $1500 - 500(0.8)^n > 1450$, i.e. $(0.8)^n < 0.1$.

Take logs: $n \ln 0.8 < \ln 0.1$. Since $\ln 0.8 < 0$ the inequality reverses: $n > \dfrac{\ln 0.1}{\ln 0.8} = 10.32\ldots$

So $n = 11$: the population first exceeds $1450$ after $11$ years ($P_{10} \approx 1446$, $P_{11} \approx 1457$).
