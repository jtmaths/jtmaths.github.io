1 The Idea Behind Substitution

Substitution is the chain rule run backwards, done formally. You replace an awkward part of the integrand with a new variable $u$, so that the whole integral becomes a standard one in $u$.

If $u = \mathrm{g}(x)$ then $\dfrac{du}{dx} = \mathrm{g}'(x)$, which we use in the form $dx = \dfrac{du}{\mathrm{g}'(x)}$. Every part of the integral — the integrand, the $dx$ and (for a definite integral) the limits — must be rewritten in terms of $u$ before you integrate.
The method
① Choose $u$  ·  ② Find $\dfrac{du}{dx}$ and replace $dx$  ·  ③ Rewrite everything in $u$
④ Integrate  ·  ⑤ Substitute back (or use $u$-limits)
Worked Example 1 — A substitution you could also spot

Use the substitution $u = x^3 + 2$ to find $\displaystyle\int 6x^2(x^3+2)^4\,dx$.

①$\dfrac{du}{dx} = 3x^2$, so $dx = \dfrac{du}{3x^2}$.
②$\displaystyle\int 6x^2 u^4 \cdot \frac{du}{3x^2} = \int 2u^4\,du$ — the $x^2$ cancels.
③$= \tfrac{2}{5}u^5 + c$
④$= \tfrac{2}{5}(x^3+2)^5 + c$
If every $x$ does not disappear at step ②, either the substitution is wrong or you need to express the leftover $x$ in terms of $u$ (Example 2).
Worked Example 2 — Expressing the leftover $x$ in terms of $u$

Use the substitution $u = x + 2$ to find $\displaystyle\int x\sqrt{x+2}\,dx$.

①$\dfrac{du}{dx} = 1$ so $dx = du$, and $x = u - 2$.
②$\displaystyle\int (u-2)u^{1/2}\,du = \int \left(u^{3/2} - 2u^{1/2}\right)du$
③$= \tfrac{2}{5}u^{5/2} - \tfrac{4}{3}u^{3/2} + c$
④$= \tfrac{2}{5}(x+2)^{5/2} - \tfrac{4}{3}(x+2)^{3/2} + c$

Worked Example 3 — An exponential substitution

Use $u = 1 + e^x$ to find $\displaystyle\int \frac{e^x}{(1+e^x)^2}\,dx$.

①$\dfrac{du}{dx} = e^x$, so $e^x\,dx = du$.
②$\displaystyle\int \frac{1}{u^2}\,du = -\frac{1}{u} + c$
③$= -\dfrac{1}{1+e^x} + c$
Worked Example 4 — Odd powers of sine

Using $u = \cos x$, find $\displaystyle\int \sin^3 x\,dx$.

①Split off one $\sin x$: $\sin^3 x = (1 - \cos^2 x)\sin x$.
②$\dfrac{du}{dx} = -\sin x$, so $\sin x\,dx = -du$.
③$\displaystyle\int (1-u^2)(-1)\,du = -u + \tfrac{1}{3}u^3 + c$
④$= -\cos x + \tfrac{1}{3}\cos^3 x + c$
3 Definite Integrals: Changing the Limits
The limits on a $dx$ integral are $x$-values. Once the integral is in terms of $u$, the limits must be $u$-values. Convert them using the substitution, and then you never need to go back to $x$.
Worked Example 5 — Changing limits

Use $u = x + 1$ to evaluate $\displaystyle\int_0^3 \frac{x}{\sqrt{x+1}}\,dx$.

①$dx = du$, $x = u - 1$. Limits: $x = 0 \Rightarrow u = 1$; $x = 3 \Rightarrow u = 4$.
②$\displaystyle\int_1^4 \frac{u-1}{u^{1/2}}\,du = \int_1^4\left(u^{1/2} - u^{-1/2}\right)du$
③$= \Big[\tfrac{2}{3}u^{3/2} - 2u^{1/2}\Big]_1^4 = \left(\tfrac{16}{3} - 4\right) - \left(\tfrac{2}{3} - 2\right)$
④$= \tfrac{4}{3} + \tfrac{4}{3} = \tfrac{8}{3}$
Worked Example 6 — A root substitution

Use $u = 1 + \sqrt{x}$ to show that $\displaystyle\int_0^4 \frac{1}{1+\sqrt{x}}\,dx = 4 - 2\ln 3$.

①$\sqrt{x} = u - 1$, so $x = (u-1)^2$ and $dx = 2(u-1)\,du$.
②Limits: $x = 0 \Rightarrow u = 1$; $x = 4 \Rightarrow u = 3$.
③$\displaystyle\int_1^3 \frac{2(u-1)}{u}\,du = \int_1^3\left(2 - \frac{2}{u}\right)du$
④$= \Big[2u - 2\ln u\Big]_1^3 = (6 - 2\ln 3) - (2 - 0) = 4 - 2\ln 3$ ✓
Writing $x$ in terms of $u$ and differentiating that is often easier than differentiating $u$ with respect to $x$.
Worked Example 7 — A logarithmic substitution

Evaluate $\displaystyle\int_1^e \frac{(\ln x)^2}{x}\,dx$ using $u = \ln x$.

①$\dfrac{du}{dx} = \dfrac{1}{x}$, so $\dfrac{1}{x}\,dx = du$.
②Limits: $x = 1 \Rightarrow u = 0$; $x = e \Rightarrow u = 1$.
③$\displaystyle\int_0^1 u^2\,du = \Big[\tfrac{1}{3}u^3\Big]_0^1 = \tfrac{1}{3}$
4 Trigonometric Substitutions

Sometimes $x$ itself is replaced by a function, such as $x = \sin\theta$. The aim is to use $1 - \sin^2\theta = \cos^2\theta$ to remove a square root.

Worked Example 8 — The area of a quarter circle

Use $x = \sin\theta$ to show that $\displaystyle\int_0^1\sqrt{1-x^2}\,dx = \frac{\pi}{4}$.

①$\dfrac{dx}{d\theta} = \cos\theta$, so $dx = \cos\theta\,d\theta$.
②Limits: $x = 0 \Rightarrow \theta = 0$; $x = 1 \Rightarrow \theta = \tfrac{\pi}{2}$.
③$\sqrt{1 - \sin^2\theta} = \sqrt{\cos^2\theta} = \cos\theta$ (positive for $0 \leqslant \theta \leqslant \tfrac{\pi}{2}$).
④$\displaystyle\int_0^{\pi/2}\cos^2\theta\,d\theta = \Big[\tfrac{1}{2}\theta + \tfrac{1}{4}\sin 2\theta\Big]_0^{\pi/2} = \tfrac{\pi}{4}$ ✓
This is a quarter of the unit circle $x^2 + y^2 = 1$, whose area is $\tfrac{1}{4}\pi(1)^2$ — a reassuring check.
Three classic slips: forgetting to replace $dx$ (writing $\int \ldots\,du$ with no $\dfrac{du}{dx}$ factor); keeping the old $x$-limits; and substituting back into $x$ and using $u$-limits — do one or the other.
5 Quick Reference

Replace dx

$dx = \dfrac{du}{du/dx}$, or differentiate $x$ in terms of $u$.

Everything in u

No $x$ may remain before you integrate.

Leftover x

Rearrange the substitution: e.g. $x = u - 2$.

Limits

Convert to $u$-limits; then no need to go back.

Indefinite

Substitute back to $x$ and add $+\,c$.

Function + derivative

Let $u$ be the function.

√(a² − x²)

$x = a\sin\theta$, then $\cos^2\theta$ identity.

Odd power of sin

Save one $\sin x$; let $u = \cos x$.

6 Practice Questions
Question 1

Use the substitution $u = x^2 - 3$ to find $\displaystyle\int 2x(x^2-3)^6\,dx$.

▶ Show solution

$\dfrac{du}{dx} = 2x$, so $2x\,dx = du$.

$\displaystyle\int u^6\,du = \tfrac{1}{7}u^7 + c = \tfrac{1}{7}(x^2-3)^7 + c$

Question 2

Use the substitution $u = x - 1$ to find $\displaystyle\int x(x-1)^5\,dx$.

▶ Show solution

$dx = du$ and $x = u + 1$.

$\displaystyle\int (u+1)u^5\,du = \int (u^6 + u^5)\,du = \tfrac{1}{7}u^7 + \tfrac{1}{6}u^6 + c$

$= \tfrac{1}{7}(x-1)^7 + \tfrac{1}{6}(x-1)^6 + c$

Question 3

Use the substitution $u = x^2$ to find the exact value of $\displaystyle\int_0^1 x e^{x^2}\,dx$.

▶ Show solution

$du = 2x\,dx$, so $x\,dx = \tfrac{1}{2}du$. Limits: $u = 0$ to $u = 1$.

$\displaystyle\int_0^1 \tfrac{1}{2}e^u\,du = \Big[\tfrac{1}{2}e^u\Big]_0^1 = \tfrac{1}{2}(e - 1)$

Question 4

Use the substitution $u = x - 1$ to evaluate $\displaystyle\int_2^5 \frac{x}{\sqrt{x-1}}\,dx$.

▶ Show solution

$dx = du$, $x = u + 1$. Limits: $x = 2 \Rightarrow u = 1$; $x = 5 \Rightarrow u = 4$.

$\displaystyle\int_1^4 \left(u^{1/2} + u^{-1/2}\right)du = \Big[\tfrac{2}{3}u^{3/2} + 2u^{1/2}\Big]_1^4$

$= \left(\tfrac{16}{3} + 4\right) - \left(\tfrac{2}{3} + 2\right) = \tfrac{14}{3} + 2 = \tfrac{20}{3}$

Question 5

Use the substitution $u = \sin x$ to find the exact value of $\displaystyle\int_0^{\pi/2}\cos x\,e^{\sin x}\,dx$.

▶ Show solution

$du = \cos x\,dx$. Limits: $x = 0 \Rightarrow u = 0$; $x = \tfrac{\pi}{2} \Rightarrow u = 1$.

$\displaystyle\int_0^1 e^u\,du = e - 1$

Question 6

Use the substitution $u = \cos x$ to show that $\displaystyle\int_0^{\pi/3}\sin x\cos^2 x\,dx = \frac{7}{24}$.

▶ Show solution

$du = -\sin x\,dx$. Limits: $x = 0 \Rightarrow u = 1$; $x = \tfrac{\pi}{3} \Rightarrow u = \tfrac{1}{2}$.

$\displaystyle\int_1^{1/2} -u^2\,du = \int_{1/2}^1 u^2\,du$ (swapping the limits removes the minus sign).

$= \Big[\tfrac{1}{3}u^3\Big]_{1/2}^1 = \tfrac{1}{3}\left(1 - \tfrac{1}{8}\right) = \tfrac{7}{24}$ ✓

Question 7

Use the substitution $u = \sqrt{x}$ to show that $\displaystyle\int_1^9 \frac{1}{x + \sqrt{x}}\,dx = 2\ln 2$.

▶ Show solution

$x = u^2$, so $dx = 2u\,du$. Limits: $u = 1$ to $u = 3$.

$\displaystyle\int_1^3 \frac{2u}{u^2 + u}\,du = \int_1^3 \frac{2}{u + 1}\,du$

$= \Big[2\ln(u+1)\Big]_1^3 = 2\ln 4 - 2\ln 2 = 2\ln 2$ ✓

Question 8

Use the substitution $x = 2\sin\theta$ to find the exact value of $\displaystyle\int_0^{\sqrt{3}}\sqrt{4 - x^2}\,dx$.

▶ Show solution

$dx = 2\cos\theta\,d\theta$. Limits: $x = 0 \Rightarrow \theta = 0$; $x = \sqrt{3} \Rightarrow \sin\theta = \tfrac{\sqrt{3}}{2}$, $\theta = \tfrac{\pi}{3}$.

$\sqrt{4 - 4\sin^2\theta} = 2\cos\theta$, so the integrand becomes $2\cos\theta \times 2\cos\theta = 4\cos^2\theta$.

$\displaystyle\int_0^{\pi/3}4\cos^2\theta\,d\theta = \int_0^{\pi/3}2(1 + \cos 2\theta)\,d\theta = \Big[2\theta + \sin 2\theta\Big]_0^{\pi/3}$

$= \dfrac{2\pi}{3} + \sin\dfrac{2\pi}{3} = \dfrac{2\pi}{3} + \dfrac{\sqrt{3}}{2}$

Question 9

Use the substitution $u = e^x + 1$ to show that $\displaystyle\int_0^{\ln 3}\frac{e^{2x}}{e^x + 1}\,dx = 2 - \ln 2$.

▶ Show solution

$du = e^x\,dx$, and $e^{2x} = e^x \cdot e^x = (u - 1)e^x$.

Limits: $x = 0 \Rightarrow u = 2$; $x = \ln 3 \Rightarrow u = 4$.

$\displaystyle\int_2^4 \frac{u-1}{u}\,du = \int_2^4\left(1 - \frac{1}{u}\right)du = \Big[u - \ln u\Big]_2^4$

$= (4 - \ln 4) - (2 - \ln 2) = 2 - \ln 2$ ✓

Question 10

The curve $C$ has equation $y = \dfrac{x^3}{\sqrt{1 + x^2}}$.

(a) Show that the substitution $u = 1 + x^2$ transforms $\displaystyle\int_0^{\sqrt{3}}\frac{x^3}{\sqrt{1+x^2}}\,dx$ into $\displaystyle\frac{1}{2}\int_1^4\frac{u-1}{\sqrt{u}}\,du$.   (b) Hence find the exact area of the region bounded by $C$, the $x$-axis and the line $x = \sqrt{3}$.   (c) A student claims that $\displaystyle\int_{-\sqrt{3}}^{\sqrt{3}}\frac{x^3}{\sqrt{1+x^2}}\,dx$ gives the total area between $C$ and the $x$-axis for $-\sqrt{3} \leqslant x \leqslant \sqrt{3}$. Explain why the student is wrong and state the correct total area.

▶ Show solution

(a) $du = 2x\,dx$, so $x\,dx = \tfrac{1}{2}du$. Write $x^3\,dx = x^2 \cdot x\,dx = (u - 1)\cdot\tfrac{1}{2}du$.

Limits: $x = 0 \Rightarrow u = 1$; $x = \sqrt{3} \Rightarrow u = 4$. So the integral is $\tfrac{1}{2}\displaystyle\int_1^4 \frac{u-1}{\sqrt{u}}\,du$ ✓

(b) $\tfrac{1}{2}\displaystyle\int_1^4\left(u^{1/2} - u^{-1/2}\right)du = \tfrac{1}{2}\Big[\tfrac{2}{3}u^{3/2} - 2u^{1/2}\Big]_1^4$

$= \tfrac{1}{2}\left[\left(\tfrac{16}{3} - 4\right) - \left(\tfrac{2}{3} - 2\right)\right] = \tfrac{1}{2} \times \tfrac{8}{3} = \tfrac{4}{3}$

The curve is above the axis for $x > 0$, so the area is $\tfrac{4}{3}$.

(c) Replacing $x$ by $-x$ changes the sign of $y$, so the curve has rotational symmetry about the origin. The region for $-\sqrt{3} \leqslant x \leqslant 0$ lies below the axis and its integral is $-\tfrac{4}{3}$; the two parts cancel to give $0$.

The total area is $\tfrac{4}{3} + \tfrac{4}{3} = \tfrac{8}{3}$.
