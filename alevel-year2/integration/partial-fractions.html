1 Why Split the Fraction?

There is no direct rule for $\displaystyle\int\frac{5x+1}{(x+1)(x-1)}\,dx$. But each partial fraction such as $\dfrac{3}{x-1}$ integrates straight to a logarithm. So the plan is: split first (see Algebraic and Partial Fractions), then integrate each piece.

PieceIntegral
$\dfrac{A}{x - a}$$A\ln|x - a| + c$
$\dfrac{A}{bx + c}$$\dfrac{A}{b}\ln|bx + c| + c$
$\dfrac{A}{(x - a)^2}$$-\dfrac{A}{x - a} + c$  (a power, not a log)
The forms you need
$\dfrac{px + q}{(x-a)(x-b)} \equiv \dfrac{A}{x-a} + \dfrac{B}{x-b}$  ·  $\dfrac{\ldots}{(x-a)(x-b)^2} \equiv \dfrac{A}{x-a} + \dfrac{B}{x-b} + \dfrac{C}{(x-b)^2}$
Check the fraction is proper first. If the degree of the numerator is the same as (or bigger than) the denominator, divide first to get a polynomial plus a proper fraction (Section 4).
2 Distinct Linear Factors
Worked Example 1 — Split and integrate

Find $\displaystyle\int\frac{5x+1}{(x+1)(x-1)}\,dx$.

①$5x + 1 \equiv A(x+1) + B(x-1)$ where $\dfrac{5x+1}{(x+1)(x-1)} \equiv \dfrac{A}{x-1} + \dfrac{B}{x+1}$.
②$x = 1$: $6 = 2A$, so $A = 3$.  $x = -1$: $-4 = -2B$, so $B = 2$.
③$\displaystyle\int\left(\frac{3}{x-1} + \frac{2}{x+1}\right)dx = 3\ln|x-1| + 2\ln|x+1| + c$
You can combine with log laws — $\ln\left|(x-1)^3(x+1)^2\right| + c$ — but it is not required unless the question asks for a particular form.
Worked Example 2 — A definite integral, answer as a single log

Show that $\displaystyle\int_2^4\frac{1}{x^2 - 1}\,dx = \tfrac{1}{2}\ln\tfrac{9}{5}$.

①$\dfrac{1}{(x-1)(x+1)} \equiv \dfrac{1/2}{x-1} - \dfrac{1/2}{x+1}$ (cover-up: $x = 1$ gives $\tfrac{1}{2}$, $x = -1$ gives $-\tfrac{1}{2}$).
②$\displaystyle\int = \tfrac{1}{2}\ln|x-1| - \tfrac{1}{2}\ln|x+1| = \tfrac{1}{2}\ln\left|\frac{x-1}{x+1}\right|$
③$\tfrac{1}{2}\left[\ln\tfrac{3}{5} - \ln\tfrac{1}{3}\right] = \tfrac{1}{2}\ln\left(\tfrac{3}{5} \times 3\right) = \tfrac{1}{2}\ln\tfrac{9}{5}$ ✓
Worked Example 3 — A factor of the form $(bx + c)$

Find $\displaystyle\int\frac{x}{(x+1)(2x+1)}\,dx$.

①$x \equiv A(2x+1) + B(x+1)$.  $x = -1$: $-1 = -A$, $A = 1$.  $x = -\tfrac{1}{2}$: $-\tfrac{1}{2} = \tfrac{1}{2}B$, $B = -1$.
②$\displaystyle\int\left(\frac{1}{x+1} - \frac{1}{2x+1}\right)dx$
③$= \ln|x+1| - \tfrac{1}{2}\ln|2x+1| + c$
The $\tfrac{1}{2}$ comes from the reverse chain rule on $(2x+1)$. Missing it is the commonest error on this page.
3 Repeated Linear Factors
A squared factor $(x - b)^2$ produces two fractions: $\dfrac{B}{x-b}$, which gives a log, and $\dfrac{C}{(x-b)^2} = C(x-b)^{-2}$, which integrates as a power to $-\dfrac{C}{x-b}$.
Worked Example 4 — A repeated factor

Find $\displaystyle\int\frac{x+5}{(x-1)(x+1)^2}\,dx$, and hence evaluate it between $x = 2$ and $x = 3$.

①$x + 5 \equiv A(x+1)^2 + B(x-1)(x+1) + C(x-1)$
②$x = 1$: $6 = 4A$, $A = \tfrac{3}{2}$.  $x = -1$: $4 = -2C$, $C = -2$.
③Compare $x^2$: $0 = A + B$, so $B = -\tfrac{3}{2}$.
④$\displaystyle\int\left(\frac{3/2}{x-1} - \frac{3/2}{x+1} - \frac{2}{(x+1)^2}\right)dx = \tfrac{3}{2}\ln|x-1| - \tfrac{3}{2}\ln|x+1| + \frac{2}{x+1} + c$
⑤From $2$ to $3$: $\tfrac{3}{2}\left(\ln 2 - \ln 4 - \ln 1 + \ln 3\right) + \left(\tfrac{2}{4} - \tfrac{2}{3}\right)$
⑥$= \tfrac{3}{2}\ln\tfrac{3}{2} - \tfrac{1}{6}$  ($\approx 0.441$)
Substituting the two "easy" values finds $A$ and $C$; comparing the $x^2$ coefficients is then the quickest way to get $B$.
4 Improper Fractions
Worked Example 5 — Divide first

Show that $\displaystyle\int_2^3\frac{x^2+1}{x^2-1}\,dx = 1 + \ln\tfrac{3}{2}$.

①Same degree top and bottom: $\dfrac{x^2+1}{x^2-1} = \dfrac{(x^2-1) + 2}{x^2-1} = 1 + \dfrac{2}{x^2-1}$.
②$\dfrac{2}{(x-1)(x+1)} \equiv \dfrac{1}{x-1} - \dfrac{1}{x+1}$
③$\displaystyle\int_2^3\left(1 + \frac{1}{x-1} - \frac{1}{x+1}\right)dx = \Big[x + \ln(x-1) - \ln(x+1)\Big]_2^3$
④$= (3 + \ln 2 - \ln 4) - (2 + 0 - \ln 3) = 1 + \ln\dfrac{2 \times 3}{4} = 1 + \ln\tfrac{3}{2}$ ✓
Worked Example 6 — Always look for cancelling

Evaluate $\displaystyle\int_2^3\frac{x^2 + x}{x^2 - 1}\,dx$.

①Factorise: $\dfrac{x(x+1)}{(x-1)(x+1)} = \dfrac{x}{x-1}$ — a common factor cancels.
②$\dfrac{x}{x-1} = \dfrac{(x-1)+1}{x-1} = 1 + \dfrac{1}{x-1}$
③$\Big[x + \ln(x-1)\Big]_2^3 = (3 + \ln 2) - (2 + 0) = 1 + \ln 2$
Do not let a definite integral cross an asymptote. $\displaystyle\int_0^2\frac{1}{x^2-1}\,dx$ is meaningless with these methods — the integrand is undefined at $x = 1$. Always check the denominator is non-zero on the whole interval.
5 Quick Reference

Step 1

Proper? If not, divide first.

Step 2

Factorise the denominator; cancel if possible.

Step 3

Split into partial fractions; check by recombining.

A/(x − a)

$A\ln|x-a|$

A/(bx + c)

$\tfrac{A}{b}\ln|bx+c|$ — divide by $b$.

A/(x − a)²

$-\dfrac{A}{x-a}$ — no log.

Single log

Combine with $\ln a - \ln b = \ln\tfrac{a}{b}$.

Limits

Never across a value that makes a denominator zero.

6 Practice Questions
Question 1

Find $\displaystyle\int\frac{3}{(x+1)(x-2)}\,dx$.

▶ Show solution

$3 \equiv A(x+1) + B(x-2)$ for $\dfrac{A}{x-2} + \dfrac{B}{x+1}$:  $x = 2$: $A = 1$;  $x = -1$: $B = -1$.

$\displaystyle\int\left(\frac{1}{x-2} - \frac{1}{x+1}\right)dx = \ln|x-2| - \ln|x+1| + c = \ln\left|\frac{x-2}{x+1}\right| + c$

Question 2

Find $\displaystyle\int\frac{7x-1}{(x-1)(x+2)}\,dx$.

▶ Show solution

$7x - 1 \equiv A(x+2) + B(x-1)$.  $x = 1$: $6 = 3A$, $A = 2$.  $x = -2$: $-15 = -3B$, $B = 5$.

$= 2\ln|x-1| + 5\ln|x+2| + c$

Question 3

Show that $\displaystyle\int_3^5\frac{2}{x^2-4}\,dx = \tfrac{1}{2}\ln\tfrac{15}{7}$.

▶ Show solution

$\dfrac{2}{(x-2)(x+2)} \equiv \dfrac{1/2}{x-2} - \dfrac{1/2}{x+2}$

$\tfrac{1}{2}\Big[\ln(x-2) - \ln(x+2)\Big]_3^5 = \tfrac{1}{2}\left[\ln\tfrac{3}{7} - \ln\tfrac{1}{5}\right] = \tfrac{1}{2}\ln\tfrac{15}{7}$ ✓

Question 4

Find the exact value of $\displaystyle\int_0^1\frac{x+3}{(x+1)(x+2)}\,dx$, giving your answer as a single logarithm.

▶ Show solution

$x + 3 \equiv A(x+2) + B(x+1)$.  $x = -1$: $A = 2$.  $x = -2$: $1 = -B$, $B = -1$.

$\Big[2\ln(x+1) - \ln(x+2)\Big]_0^1 = (2\ln 2 - \ln 3) - (0 - \ln 2) = 3\ln 2 - \ln 3 = \ln\tfrac{8}{3}$

Question 5

Show that $\displaystyle\int_1^2\frac{x+4}{(2x-1)(x+1)}\,dx = \ln\left(2\sqrt{3}\right)$.

▶ Show solution

$x + 4 \equiv A(x+1) + B(2x-1)$.  $x = \tfrac{1}{2}$: $\tfrac{9}{2} = \tfrac{3}{2}A$, $A = 3$.  $x = -1$: $3 = -3B$, $B = -1$.

$\displaystyle\int\left(\frac{3}{2x-1} - \frac{1}{x+1}\right)dx = \tfrac{3}{2}\ln|2x-1| - \ln|x+1|$

$\left(\tfrac{3}{2}\ln 3 - \ln 3\right) - \left(0 - \ln 2\right) = \tfrac{1}{2}\ln 3 + \ln 2 = \ln\left(2\sqrt{3}\right)$ ✓

Question 6

Find the exact value of $\displaystyle\int_0^1\frac{2x+3}{(x+1)^2}\,dx$.

▶ Show solution

$2x + 3 \equiv A(x+1) + B$, so $A = 2$ and (at $x = -1$) $B = 1$: $\dfrac{2}{x+1} + \dfrac{1}{(x+1)^2}$.

$\left[2\ln(x+1) - \dfrac{1}{x+1}\right]_0^1 = \left(2\ln 2 - \tfrac{1}{2}\right) - (0 - 1) = 2\ln 2 + \tfrac{1}{2}$

Question 7

Express $\dfrac{1}{x(x+1)^2}$ in partial fractions, and hence show that $\displaystyle\int_1^2\frac{1}{x(x+1)^2}\,dx = \ln\tfrac{4}{3} - \tfrac{1}{6}$.

▶ Show solution

$1 \equiv A(x+1)^2 + Bx(x+1) + Cx$.  $x = 0$: $A = 1$.  $x = -1$: $1 = -C$, $C = -1$.  $x^2$: $0 = A + B$, $B = -1$.

$\dfrac{1}{x} - \dfrac{1}{x+1} - \dfrac{1}{(x+1)^2}$

Integral: $\ln x - \ln(x+1) + \dfrac{1}{x+1}$.

$\left(\ln 2 - \ln 3 + \tfrac{1}{3}\right) - \left(0 - \ln 2 + \tfrac{1}{2}\right) = \ln\tfrac{4}{3} - \tfrac{1}{6}$ ✓

Question 8

Find the exact value of $\displaystyle\int_3^4\frac{5}{x^2 + x - 6}\,dx$.

▶ Show solution

$x^2 + x - 6 = (x+3)(x-2)$.  $5 \equiv A(x-2) + B(x+3)$:  $x = 2$: $B = 1$;  $x = -3$: $A = -1$.

$\Big[\ln(x-2) - \ln(x+3)\Big]_3^4 = \ln\tfrac{2}{7} - \ln\tfrac{1}{6} = \ln\tfrac{12}{7}$

Question 9

Find $\displaystyle\int\frac{x^2+1}{x^2-1}\,dx$ and explain why $\displaystyle\int_0^2\frac{x^2+1}{x^2-1}\,dx$ cannot be found this way.

▶ Show solution

As in Worked Example 5, the integrand is $1 + \dfrac{1}{x-1} - \dfrac{1}{x+1}$.

$\displaystyle\int = x + \ln|x-1| - \ln|x+1| + c = x + \ln\left|\frac{x-1}{x+1}\right| + c$

The range $0 \leqslant x \leqslant 2$ contains $x = 1$, where the denominator is zero and the integrand has a vertical asymptote. The area is not finite there, so the integral is not defined.

Question 10

$\mathrm{f}(x) = \dfrac{2x^2 + 3x - 1}{(x+1)(x-1)}$, $x > 1$.

(a) Show that $\mathrm{f}(x)$ can be written as $A + \dfrac{B}{x-1} + \dfrac{C}{x+1}$ and find $A$, $B$ and $C$.   (b) The region $R$ is bounded by the curve $y = \mathrm{f}(x)$, the $x$-axis and the lines $x = 2$ and $x = 4$. Show that the area of $R$ is $4 + \ln 15$.   (c) Explain why the condition $x > 1$ is needed.

▶ Show solution

(a) $(x+1)(x-1) = x^2 - 1$. Then $2x^2 + 3x - 1 = 2(x^2 - 1) + 3x + 1$, so $\mathrm{f}(x) = 2 + \dfrac{3x+1}{x^2-1}$.

$3x + 1 \equiv B(x+1) + C(x-1)$.  $x = 1$: $4 = 2B$, $B = 2$.  $x = -1$: $-2 = -2C$, $C = 1$.

$\mathrm{f}(x) = 2 + \dfrac{2}{x-1} + \dfrac{1}{x+1}$, so $A = 2$, $B = 2$, $C = 1$.

(b) For $x > 1$ every term is positive, so the curve is above the axis.

$\Big[2x + 2\ln(x-1) + \ln(x+1)\Big]_2^4 = (8 + 2\ln 3 + \ln 5) - (4 + 0 + \ln 3)$

$= 4 + \ln 3 + \ln 5 = 4 + \ln 15$ ✓

(c) $\mathrm{f}$ is undefined at $x = \pm 1$. Restricting to $x > 1$ keeps the curve on one continuous branch, so the region between $x = 2$ and $x = 4$ is well defined and the modulus signs in the logs can be dropped.
