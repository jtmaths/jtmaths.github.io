# Parametric Equations

A new way to describe a curve: give *x* and *y* separately, each as a function of a third variable called the parameter.
This is the natural language for anything that moves, and it is used again in parametric differentiation and in mechanics.

* [An Overview](overview.html) — what a parameter is, how to plot and convert, and the common mistakes
