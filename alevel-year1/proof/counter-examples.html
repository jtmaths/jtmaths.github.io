1 What a Counter-example Is
A counter-example is a single case that satisfies all the conditions of a statement but for which the conclusion is false. One counter-example is enough to prove that a general statement is false.

Proving and disproving are not equally hard. To prove "for all $n$, …" you need a general argument that works for every $n$. To disprove it, you need just one value of $n$ where it fails.

The logic of disproof
Claim: "For every $x$ in a set, $P(x)$ is true."
Disproof: "Here is one particular $x$ in the set for which $P(x)$ is false."
To show it is trueTo show it is false
"For all …"A general proof (deduction or exhaustion)One counter-example
"There exists …"One exampleA general proof that no case works
Examples that work prove nothing. Showing that a claim holds for $n = 1, 2, 3, \dots, 100$ does not prove it. The statement "$n^2 + n + 41$ is prime" is true for $n = 1$ to $39$ — and false for $n = 40$.
2 Where to Look for a Counter-example

Many false claims are written by someone who only pictured positive whole numbers bigger than $1$. The values below break such claims surprisingly often — try them first.

Look at the structure. A formula like $n^2 + n + c$ will be a multiple of $c$ when $n = c$ (since $c^2 + c + c = c(c + 2)$). Spotting why a claim might fail is faster than trying random numbers.
Worked Example 1 — A fraction breaks an inequality

Disprove the statement "$x^2 > x$ for all real numbers $x$."

①Try a number between $0$ and $1$: let $x = \tfrac12$.
②$x^2 = \tfrac14$, and $\tfrac14 < \tfrac12$, so $x^2 > x$ is false.
③$x = \tfrac12$ is a counter-example, so the statement is false. $\blacksquare$
$x = 1$ (where $x^2 = x$) and $x = 0$ are also counter-examples, because the statement uses the strict inequality $>$.
Worked Example 2 — The even prime

Disprove "If $p$ is prime, then $p + 1$ is even."

①The claim is really "every prime is odd". The only even prime is $2$.
②$p = 2$ is prime and $p + 1 = 3$ is odd.
③So $p = 2$ is a counter-example and the statement is false. $\blacksquare$
Worked Example 3 — Negative numbers and squaring

Disprove "For all real $a$ and $b$, if $a > b$ then $a^2 > b^2$."

①Take $a = 1$, $b = -2$. Then $a > b$ ✓.
②$a^2 = 1$ and $b^2 = 4$, so $a^2 < b^2$.
③The conditions hold but the conclusion fails, so the statement is false. $\blacksquare$
Make sure your counter-example satisfies the conditions. $a = -3$, $b = 2$ does not count — it fails the condition $a > b$, so it tells you nothing about the claim.
Worked Example 4 — A pattern that eventually fails

Disprove "$n^2 - n + 11$ is prime for every positive integer $n$."

①Spot the structure: when $n = 11$ every term contains a factor of $11$.
②$11^2 - 11 + 11 = 121 = 11 \times 11$.
③$121$ is not prime, so $n = 11$ is a counter-example. $\blacksquare$
Checking $n = 1, 2, \dots, 10$ gives $11, 13, 17, 23, 31, 41, 53, 67, 83, 101$ — all prime. A pattern that holds for ten cases can still be false.
Worked Example 5 — A famous false conjecture

Disprove "If $n$ is prime, then $2^n - 1$ is prime."

①The small cases work: $n = 2, 3, 5, 7$ give $3, 7, 31, 127$, all prime.
②Try $n = 11$, which is prime: $2^{11} - 1 = 2047$.
③$2047 = 23 \times 89$, which is not prime.
④$n = 11$ is a counter-example, so the statement is false. $\blacksquare$
A calculator is fine for finding the factors, but your written answer must show them: "$2047 = 23 \times 89$". Just writing "not prime" is not enough.
Worked Example 6 — Counter-examples in algebra

Disprove "$\sqrt{a + b} = \sqrt{a} + \sqrt{b}$ for all positive $a$ and $b$."

①Choose square numbers so the arithmetic is easy: $a = 9$, $b = 16$.
②$\sqrt{9 + 16} = \sqrt{25} = 5$, but $\sqrt{9} + \sqrt{16} = 3 + 4 = 7$.
③$5 \neq 7$, so the statement is false. $\blacksquare$
3 Writing Up a Disproof
  1. State the counter-example clearly. "Let $n = 11$."
  2. Check it meets the conditions. "$11$ is prime."
  3. Show the calculation that makes the conclusion fail. "$2^{11} - 1 = 2047 = 23 \times 89$."
  4. Conclude. "So $2^{11} - 1$ is not prime, and the statement is false."
A model answer
"When $n = 11$: $11$ is prime, but $2^{11} - 1 = 2047 = 23 \times 89$ is not prime.
Hence $n = 11$ is a counter-example and the statement is false."
Worked Example 7 — Disprove, then repair

(a) Disprove "$x^3 > x$ for all real $x$."   (b) Prove that $x^3 > x$ for all $x > 1$.

①(a) $x = -2$: $x^3 = -8$ and $-8 < -2$. So the statement is false.
②(b) $x^3 - x = x\left(x^2 - 1\right) = x(x - 1)(x + 1)$.
③If $x > 1$ then $x > 0$, $x - 1 > 0$ and $x + 1 > 0$, so the product is positive.
④So $x^3 - x > 0$, i.e. $x^3 > x$, for all $x > 1$. $\blacksquare$
Restricting the set of values is a common way to turn a false statement into a true one. The counter-example tells you which values to exclude.
4 Prove or Disprove?

Some questions do not tell you whether a statement is true. Test a few cases — especially the awkward ones — before deciding which way to go.

Strategy. Try the "usual suspects" first. If one of them fails, you have a counter-example. If they all work and you can see a reason why, write a general proof.
Worked Example 8 — Two similar-looking claims

Prove or disprove each statement.   (a) The sum of any three consecutive even numbers is a multiple of $6$.   (b) The product of any three consecutive positive integers is a multiple of $4$.

①(a) Let the numbers be $2n$, $2n + 2$, $2n + 4$ with $n \in \mathbb{Z}$.
②Sum $= 6n + 6 = 6(n + 1)$, a multiple of $6$. True, proved.
③(b) Try $1 \times 2 \times 3 = 6$, which is not a multiple of $4$.
④So the statement is false, with counter-example $1, 2, 3$.
For (b), $2 \times 3 \times 4 = 24$ is a multiple of $4$. That example does not help either way — but $1 \times 2 \times 3$ settles it. Keep looking until you find a failure or a reason.
Worked Example 9 — Irrational numbers

Disprove "The sum of two irrational numbers is always irrational."

①$\sqrt{2}$ is irrational, and so is $-\sqrt{2}$.
②$\sqrt{2} + \left(-\sqrt{2}\right) = 0$, and $0 = \tfrac01$ is rational.
③So the statement is false. $\blacksquare$
$\left(3 + \sqrt{2}\right) + \left(3 - \sqrt{2}\right) = 6$ is another counter-example. A counter-example need not be the simplest one — but simple ones are easiest to check.
5 Quick Reference

One is enough

A single counter-example disproves a "for all" statement.

Not a proof

Any number of examples that work prove nothing.

Usual suspects

$0$, $1$, negatives, fractions, $2$.

Conditions

Your example must satisfy every condition of the claim.

Show it

Write the calculation and the factors — don't just say "fails".

Conclude

"Hence … is a counter-example, so the statement is false."

Structure

$n^2 + n + c$ is divisible by $c$ when $n = c$.

Repair

Restrict the set of values to exclude the counter-example, then prove.

6 Practice Questions
Question 1

Disprove the statement "every odd number is prime."

▶ Show solution

$9$ is odd, but $9 = 3 \times 3$ is not prime.

So $9$ is a counter-example and the statement is false. ($1$ also works, since $1$ is not prime.)

Question 2

Disprove "$\sqrt{x^2} = x$ for all real $x$."

▶ Show solution

Let $x = -3$. Then $\sqrt{x^2} = \sqrt{9} = 3$, but $x = -3$.

$3 \neq -3$, so $x = -3$ is a counter-example and the statement is false. (In fact $\sqrt{x^2} = |x|$.)

Question 3

Disprove "$\dfrac{1}{x} < x$ for all real $x \neq 0$."

▶ Show solution

Let $x = \tfrac12$. Then $\dfrac1x = 2$, and $2 > \tfrac12$.

So $\dfrac1x < x$ is false when $x = \tfrac12$, and the statement is false.

Question 4

Disprove "If $a^2 > b^2$, then $a > b$."

▶ Show solution

Let $a = -3$, $b = 1$. Then $a^2 = 9 > 1 = b^2$, so the condition holds.

But $a = -3 < 1 = b$, so the conclusion fails. The statement is false.

Question 5

Show that "$n^2 + 3n + 1$ is prime for every positive integer $n$" is false.

▶ Show solution

$n = 1, 2, 3, 4, 5$ give $5, 11, 19, 29, 41$ — all prime.

$n = 6$: $36 + 18 + 1 = 55 = 5 \times 11$, which is not prime.

So $n = 6$ is a counter-example and the statement is false.

Question 6

Disprove "$2^n + 1$ is prime for every positive integer $n$."

▶ Show solution

$n = 1$: $3$, prime. $n = 2$: $5$, prime.

$n = 3$: $2^3 + 1 = 9 = 3 \times 3$, not prime.

So $n = 3$ is a counter-example and the statement is false.

Question 7

A student says: "The sum of two prime numbers is never prime, because adding two odd numbers gives an even number." Find a counter-example, and explain the flaw in the student's reasoning.

▶ Show solution

$2 + 3 = 5$, and $5$ is prime. So the statement is false.

The flaw: the student assumed every prime is odd. The prime $2$ is even, so "odd + odd" does not cover every pair of primes.

Question 8

Disprove "$(a + b)^2 = a^2 + b^2$ for all real $a$ and $b$." Then find all pairs $(a, b)$ for which it is true.

▶ Show solution

Let $a = b = 1$: $(1 + 1)^2 = 4$, but $1^2 + 1^2 = 2$. So the statement is false.

In general $(a+b)^2 = a^2 + 2ab + b^2$, so the equation holds exactly when $2ab = 0$.

It is true precisely when $a = 0$ or $b = 0$.

Question 9

Prove or disprove each statement.   (a) The sum of any three consecutive integers is a multiple of $6$.   (b) The product of any two consecutive integers is even.

▶ Show solution

(a) False. $2 + 3 + 4 = 9$, which is not a multiple of $6$. (The sum is always $3(n+1)$, a multiple of $3$, but only a multiple of $6$ when $n + 1$ is even.)

(b) True. Let the integers be $n$ and $n + 1$.

If $n$ is even, $n = 2k$ and $n(n+1) = 2k(n+1)$ is even.

If $n$ is odd, $n + 1 = 2k$ is even, and $n(n+1) = 2kn$ is even.

Every integer is even or odd, so the product is always even.

Question 10

A student claims that $x^2 \geqslant 4x - 3$ for all real values of $x$.

(a) Find a counter-example to the claim.   (b) Find the complete set of values of $x$ for which the claim fails.   (c) Prove that $x^2 \geqslant 4x - 4$ for all real $x$, and state when equality holds.

▶ Show solution

(a) Let $x = 2$: $x^2 = 4$ and $4x - 3 = 5$. Since $4 < 5$, the claim fails at $x = 2$.

(b) The claim fails when $x^2 < 4x - 3$, i.e. $x^2 - 4x + 3 < 0$.

$(x - 1)(x - 3) < 0$. The parabola opens upwards with roots $1$ and $3$, so it is negative between them.

The claim fails exactly for $1 < x < 3$, i.e. $\{x : 1 < x < 3\}$.

(c) $x^2 - (4x - 4) = x^2 - 4x + 4 = (x - 2)^2 \geqslant 0$ for all real $x$.

So $x^2 \geqslant 4x - 4$ for all real $x$, with equality only when $x = 2$.
