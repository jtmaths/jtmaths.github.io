1 Integration Reverses Differentiation
If $\dfrac{d}{dx}\big(\mathrm{F}(x)\big) = \mathrm{f}(x)$, then $\mathrm{F}(x)$ is an integral (or antiderivative) of $\mathrm{f}(x)$. We write $$\int \mathrm{f}(x)\,dx = \mathrm{F}(x) + c.$$

Think about which functions differentiate to $2x$. Certainly $x^2$ does — but so do $x^2 + 1$, $x^2 - 7$ and $x^2 + 100$, because the derivative of a constant is zero. Differentiating throws the constant away, so integrating cannot recover it. All we can say is

The constant of integration
$\displaystyle\int 2x\,dx = x^2 + c$,  where $c$ is an arbitrary constant

Geometrically, $\displaystyle\int 2x\,dx$ is a whole family of curves, each a vertical translation of the others. At any given $x$ they all have the same gradient. One extra piece of information — a point on the curve — picks out a single member of the family.

2 Integrating Powers of $x$

To differentiate $x^n$ you multiply by the power and then reduce it by one. To integrate, do the opposite in the opposite order: increase the power by one, then divide by the new power.

The power rule for integration
$\displaystyle\int x^n\,dx = \frac{x^{n+1}}{n+1} + c, \qquad n \neq -1$
$\displaystyle\int kx^n\,dx = \frac{k\,x^{n+1}}{n+1} + c$  and  $\displaystyle\int k\,dx = kx + c$

The rule works for any rational power — positive, negative or fractional — except $n = -1$. Sums and differences are integrated term by term.

Why not $n = -1$? The formula would give $\dfrac{x^0}{0}$, which is meaningless. The integral of $\dfrac1x$ does exist — it is $\ln|x| + c$ — but that belongs to Year 2.

Worked Example 1 — A polynomial

Find $\displaystyle\int \left(6x^2 - 4x + 5\right)dx$.

①$6x^2 \to \dfrac{6x^3}{3} = 2x^3$
②$-4x \to \dfrac{-4x^2}{2} = -2x^2$
③$5 \to 5x$
④$\displaystyle\int \left(6x^2 - 4x + 5\right)dx = 2x^3 - 2x^2 + 5x + c$
Check by differentiating: $\dfrac{d}{dx}\left(2x^3 - 2x^2 + 5x + c\right) = 6x^2 - 4x + 5$ ✓. This takes ten seconds and catches almost every slip.
Worked Example 2 — Negative and fractional powers

Find $\displaystyle\int \left(\frac{3}{x^2} + 4\sqrt{x}\right)dx$.

①Rewrite with indices: $3x^{-2} + 4x^{1/2}$.
②$3x^{-2} \to \dfrac{3x^{-1}}{-1} = -3x^{-1}$
③$4x^{1/2} \to \dfrac{4x^{3/2}}{3/2} = \dfrac83x^{3/2}$
④$= -\dfrac{3}{x} + \dfrac83x^{3/2} + c$
Dividing by a fraction means multiplying by its reciprocal: $\div \tfrac32$ is $\times \tfrac23$.
3 Rewrite Before You Integrate

The power rule only applies to a sum of terms $kx^n$. There is no product rule or quotient rule for integration at this level, so brackets must be expanded and fractions split first.

  • Expand any brackets.
  • Split a fraction with a single-term denominator into separate terms.
  • Write every root and reciprocal as a power of $x$.
  • Integrate term by term and add $c$.
Worked Example 3 — Expanding brackets

Find $\displaystyle\int (x+2)(x-3)\,dx$.

①Expand: $(x+2)(x-3) = x^2 - x - 6$.
②Integrate: $\tfrac13x^3 - \tfrac12x^2 - 6x + c$.
Integrating each bracket separately and multiplying the results is a classic error — differentiate that "answer" and you will not get $(x+2)(x-3)$ back.
Worked Example 4 — Splitting a fraction

Find $\displaystyle\int \frac{2x^2 + 5}{\sqrt{x}}\,dx$.

①Split: $\dfrac{2x^2}{x^{1/2}} + \dfrac{5}{x^{1/2}} = 2x^{3/2} + 5x^{-1/2}$.
②$2x^{3/2} \to \dfrac{2x^{5/2}}{5/2} = \dfrac45x^{5/2}$
③$5x^{-1/2} \to \dfrac{5x^{1/2}}{1/2} = 10x^{1/2}$
④$= \dfrac45x^{5/2} + 10\sqrt{x} + c$
Other letters. The variable need not be $x$. $\displaystyle\int \left(3t^2 - 1\right)dt = t^3 - t + c$. The $dt$ tells you which letter is the variable; any other letter is treated as a constant.
4 Finding a Curve from Its Gradient
If you know $\dfrac{dy}{dx}$ (or $\mathrm{f}'(x)$) and one point on the curve, you can find the curve exactly: integrate to get the family, then substitute the point to fix $c$.
Worked Example 5 — A curve through a given point

A curve has gradient $\dfrac{dy}{dx} = 3x^2 - 6x + 1$ and passes through $(2, 5)$. Find its equation.

①Integrate: $y = x^3 - 3x^2 + x + c$.
②Substitute $x = 2$, $y = 5$: $5 = 8 - 12 + 2 + c$.
③$5 = -2 + c$, so $c = 7$.
④$y = x^3 - 3x^2 + x + 7$
Worked Example 6 — Function notation and fractional powers

Given $\mathrm{f}'(x) = 6\sqrt{x} - \dfrac{2}{x^2}$ for $x > 0$ and $\mathrm{f}(4) = 20$, find $\mathrm{f}(x)$.

①Rewrite: $\mathrm{f}'(x) = 6x^{1/2} - 2x^{-2}$.
②Integrate: $\mathrm{f}(x) = \dfrac{6x^{3/2}}{3/2} - \dfrac{2x^{-1}}{-1} + c = 4x^{3/2} + \dfrac{2}{x} + c$.
③$\mathrm{f}(4) = 4(4)^{3/2} + \dfrac24 + c = 32 + \tfrac12 + c$.
④$32.5 + c = 20$, so $c = -12.5$.
⑤$\mathrm{f}(x) = 4x^{3/2} + \dfrac2x - \dfrac{25}{2}$
$4^{3/2} = \left(\sqrt4\right)^3 = 8$. Take the root first — the numbers stay small.
Worked Example 7 — Using a stationary point

A curve has $\dfrac{dy}{dx} = kx^2 - 12$, where $k$ is a constant. The curve has a stationary point at $(2, -10)$. Find $k$ and the equation of the curve.

①Stationary at $x = 2$ means $\dfrac{dy}{dx} = 0$ there: $4k - 12 = 0$, so $k = 3$.
②Integrate $3x^2 - 12$: $y = x^3 - 12x + c$.
③At $(2, -10)$: $-10 = 8 - 24 + c$, so $c = 6$.
④$y = x^3 - 12x + 6$
A stationary point gives you two facts: the gradient is zero there, and the point lies on the curve. Use both.
5 Integration in Context

Any rate of change can be integrated to recover the quantity itself. The constant of integration is then fixed by an initial condition — the value at the start.

Worked Example 8 — Filling a tank

Water flows into a tank so that, $t$ minutes after a tap is opened, $\dfrac{dV}{dt} = 30 - 2t$ litres per minute, for $0 \leqslant t \leqslant 15$. Initially the tank holds $100$ litres. Find $V$ in terms of $t$ and the volume when the tap closes at $t = 15$.

①Integrate with respect to $t$: $V = 30t - t^2 + c$.
②$V = 100$ when $t = 0$, so $c = 100$: $V = 30t - t^2 + 100$.
③At $t = 15$: $V = 450 - 225 + 100 = 325$ litres.
The rate $30 - 2t$ falls to zero at $t = 15$, which is why the model is only used up to then. Stating the domain of a model is part of good modelling.
6 Quick Reference

Power rule

Add one to the power, divide by the new power.

Exception

$n = -1$ is not covered at AS.

Constant

$\int k\,dx = kx + c$.

$+\,c$

Every indefinite integral needs it.

Rewrite first

Expand brackets; split fractions; roots to powers.

Roots

$\sqrt{x} = x^{1/2}$, $\dfrac{1}{\sqrt x} = x^{-1/2}$.

Finding $c$

Integrate first, then substitute the known point.

Stationary point

Gives $\dfrac{dy}{dx} = 0$ and a point on the curve.

Check

Differentiate your answer.

7 Practice Questions
Question 1

Find $\displaystyle\int 4x^3\,dx$.

▶ Show solution

$\dfrac{4x^4}{4} + c = x^4 + c$

Question 2

Find $\displaystyle\int \left(5x^4 - 6x^2 + 3\right)dx$.

▶ Show solution

$x^5 - 2x^3 + 3x + c$

Question 3

Find $\displaystyle\int \frac{6}{x^3}\,dx$.

▶ Show solution

$\dfrac{6}{x^3} = 6x^{-3}$.

$\dfrac{6x^{-2}}{-2} + c = -3x^{-2} + c = -\dfrac{3}{x^2} + c$

Question 4

Find $\displaystyle\int \left(3\sqrt{x} - \frac{1}{\sqrt{x}}\right)dx$.

▶ Show solution

Rewrite: $3x^{1/2} - x^{-1/2}$.

$3x^{1/2} \to \dfrac{3x^{3/2}}{3/2} = 2x^{3/2}$   and   $-x^{-1/2} \to -\dfrac{x^{1/2}}{1/2} = -2x^{1/2}$

$= 2x^{3/2} - 2\sqrt{x} + c$

Question 5

Find $\displaystyle\int (2x - 1)^2\,dx$.

▶ Show solution

Expand: $(2x-1)^2 = 4x^2 - 4x + 1$.

$\dfrac43x^3 - 2x^2 + x + c$

Question 6

Find $\displaystyle\int \frac{x^4 + 3x}{x^3}\,dx$.

▶ Show solution

Split: $\dfrac{x^4}{x^3} + \dfrac{3x}{x^3} = x + 3x^{-2}$.

$\tfrac12x^2 + \dfrac{3x^{-1}}{-1} + c = \tfrac12x^2 - \dfrac{3}{x} + c$

Question 7

A curve has $\dfrac{dy}{dx} = 4x - 3$ and passes through $(1, 6)$. Find its equation.

▶ Show solution

$y = 2x^2 - 3x + c$

At $(1, 6)$: $6 = 2 - 3 + c$, so $c = 7$.

$y = 2x^2 - 3x + 7$

Question 8

$\mathrm{f}'(x) = 3x^2 + \dfrac{2}{x^2}$ and $\mathrm{f}(1) = 4$. Find $\mathrm{f}(x)$ and hence $\mathrm{f}(2)$.

▶ Show solution

$\mathrm{f}'(x) = 3x^2 + 2x^{-2}$, so $\mathrm{f}(x) = x^3 - 2x^{-1} + c = x^3 - \dfrac2x + c$.

$\mathrm{f}(1) = 1 - 2 + c = 4$, so $c = 5$.

$\mathrm{f}(x) = x^3 - \dfrac2x + 5$, and $\mathrm{f}(2) = 8 - 1 + 5 = 12$.

Question 9

The gradient of a curve is $kx - 4$, where $k$ is a constant. The curve has a stationary point at $(2, -3)$. Find the equation of the curve.

▶ Show solution

Stationary at $x = 2$: $2k - 4 = 0$, so $k = 2$.

$\dfrac{dy}{dx} = 2x - 4$, so $y = x^2 - 4x + c$.

At $(2, -3)$: $-3 = 4 - 8 + c$, so $c = 1$.

$y = x^2 - 4x + 1$

Question 10

The height $h$ cm of a plant, $t$ weeks after it is planted, is modelled by $\dfrac{dh}{dt} = 2 + 3\sqrt{t}$ for $t \geqslant 1$. When $t = 1$ the plant is $5$ cm tall.

(a) Find $h$ in terms of $t$.   (b) Find the height when $t = 4$.   (c) Show that the plant grows $20$ cm between $t = 1$ and $t = 4$.   (d) Give one reason why the model is unlikely to be valid for large values of $t$.

▶ Show solution

(a) $\dfrac{dh}{dt} = 2 + 3t^{1/2}$, so $h = 2t + \dfrac{3t^{3/2}}{3/2} + c = 2t + 2t^{3/2} + c$.

When $t = 1$, $h = 5$: $5 = 2 + 2 + c$, so $c = 1$.

$h = 2t + 2t^{3/2} + 1$

(b) $h(4) = 8 + 2(8) + 1 = 25$ cm.

(c) $h(4) - h(1) = 25 - 5 = 20$ cm ✓

(d) The rate of growth $2 + 3\sqrt t$ keeps increasing, so the model predicts the plant grows faster and faster without limit. Real plants reach a maximum height, so the model must fail eventually.
